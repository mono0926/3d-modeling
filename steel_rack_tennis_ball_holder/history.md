# 履歴とプロンプト経緯 (`steel_rack_tennis_ball_holder`)

## 2026-11-12 — 初版（v1）設計・実装（C字リング皿×縦4段・最上段レッドボール兼用・1ピース一体造形版 / Issue `#38`）

### ユーザー要望・背景
- `steel_rack_tennis_racket_holder`（v4）で実機装着検証済みのスチールラック用ワンタッチロック機構を共有し、テニスボールを置けるスタンドを別途作成したい。
- 筒状だと下のボールが取り出しにくいため、手前が開いた皿型を縦に並べる方式（案1）を採用し、Bambu Lab P2S の造形サイズ内で収まるなら **4個置き** にしたい。
- 通常サイズの硬式テニスボール（基準 `φ67.0 mm`）を最優先としつつ、**一番上の段に大きめのレッドボール（`φ75〜80 mm`）を1個置くこともある** 運用に対応したい。
- 横桟から伸びる向き（上向き／下向き）は構造的にベターな方を採用したい。

### 構造判断・設計内容
1. **構造最優先の「横桟から上方向へ立ち上がる分割なし1ピース一体造形タワー」を採用**:
   - 下向き配置で必要となる2ピース差し込み継手のガタ・経年クリープやサポート材を完全に排除し、樹脂本体全高 `246.00 mm`（`<= Bambu Lab P2S 造形上限 256.00 mm`）の単一ソリッド一体構造とした。
   - 第1段C字リング皿の下部スカートを `Z = 0.00 mm` ビルドプレートへ直接接地させ、横 `77.0 mm` × 奥行 `96.3 mm` の広いU字接地ベースを形成することで、ブリム不要の高層造形安定性を確保した。
   - ボール4球分の重心が丸パイプ（`u = +5.60 mm`）より手前（`u = +65.00 mm`）にあるため、重力モーメントが上部背面ストッパー（`u = -1.06 mm`）を薄鉄板フチ裏面へ押し付ける自己倍力方向に働く。
2. **v4高保持ロック機構の100%継承 ＋ フロント指入れアーチ窓**:
   - ラケット掛け v4 で「完璧」と確認された段付き丸パイプ専用ポケット（幅 `7.70 mm`）＋ 頂点越え常時予圧ディープフック（`u = +4.55 mm`）＋ 指掛けリリースタブ（`v = +9.60 mm`）をそのまま搭載。
   - 第1段のすぐ上（`Z = 28.80 〜 73.00 mm`）に幅 `26.00 mm`・屋根傾斜 `45.0°` の切妻アーチ窓を貫通させ、手前から指を入れてリリースタブをスムーズに操作可能とした（2・3段目背後にも同様の軽量化切妻トラス窓を配置）。
3. **手前オープンC字リング皿 × 縦4段（`74.40 mm` ピッチ）＆ 完全サポートフリー下部シェル**:
   - 全4段に手前 `45.0 mm` のオープン開口（先端保護 `R2.00 mm` 付き）を設けることで、自然落下を完全に防ぎつつ、上の皿に指が当たらず約 `9〜10 mm` 持ち上げるだけで手前へサッと摘まみ出せる。
   - 2〜4段目の下部支持部は、背面ラダースパインから `45.0°` でせり上がるサイドリブ・`45.0°` 内面中空シェル・直下ボール周囲 `+5.0 mm` の `45.0°` ティアドロップ円錐ドームくり抜きを組み合わせ、下段ボール非干渉と全下面オーバーハング `<= 55.0°` の完全サポートフリー造形を両立した。
4. **1〜3段：通常硬式球専用座 ／ 4段目（最上段）：通常球＆レッドボール兼用の連続2段凹面座**:
   - **#1〜#3段**: `r = 25.30 → 29.80 mm` のテーパー座面により通常硬式球（`φ65.4〜68.6 mm`）を保持（隣接ボール間の上下隙間 `7.40 mm`）。
   - **#4段（最上段）**: 内座（`r = 24.80 → 28.80 mm`）で通常硬式球（`φ67.0 mm`）を1〜3段と同軸保持しつつ、段差角のない連続外フレア座（`r = 28.80 → 33.47 mm`）でレッドフェルト球（`φ75.0 mm`）およびレッドスポンジ球（`φ80.0 mm`）も安定保持できる設計とした。
   - 併せて、最上段の2サイズ連続凹面座と手前開口の保持感を約20分で単体確認できる薄型リングゲージ（`steel_rack_tennis_ball_holder_fit_test.step`）を同梱出力した。
