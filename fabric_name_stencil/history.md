# 履歴とプロンプト経緯

## 2026-09-02: 初期作成

**依頼内容:**
布（4×8cm）に「おなまえ」と綺麗に書くためのステンシルプレートを作成。

- フォント: ヒラギノ角ゴシック W4
- 文字は中央配置
- 縦に余裕があれば短くして良い

**設計決定:**

- font_size=20mm → 「おなまえ」の幅 約75mm、高さ 約17mm
- プレート寸法: 82mm(W) × 25mm(H) × 1.5mm(T)
  - 布80mmに対して左右1mm余裕 → 板は82mm
  - テキスト高17mm + 上下4mmずつの余白 → 板高25mm（3cmより短い設計）
- フォントパス: `/System/Library/Fonts/ヒラギノ角ゴシック W4.ttc`
- 角丸R=2mm（取り扱いやすさのため）
- ステンシル構造: 薄板（1.5mm）にテキスト形状を貫通させてくり抜き

**生成ファイル:**
薄板（1.5mm）にテキスト形状を貫通させてくり抜き

**生成ファイル:**

- `fabric_name_stencil.step.py` — build123d ソースコード
- `fabric_name_stencil.step` — STEPファイル（Bambu Studio / Fusion 読み込み可能）
- `fabric_name_stencil.stl` — STLファイル（補助確認用）
