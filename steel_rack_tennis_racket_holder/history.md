# 履歴とプロンプト経緯 (steel_rack_tennis_racket_holder)

## 2026-11-12 (v3): 実機装着写真に基づく精密ゼロガタ化 ＆ 常時予圧35°ディープフック強化

### 背景・v2 実機テストでの判明事項
- v2 の事前嵌合テストピース（`steel_rack_tennis_racket_holder_fit_test.step`）を実機印刷してスチールラックへ装着したところ、「ギリギリ使えそうだがかなり緩く、容易に脱落しそう」とのフィードバックと装着側面写真を受領した。
- 装着写真をピクセルキャリパーで実寸照合した結果、緩さと抜けやすさの直接原因が以下の **3点** にあることを特定した：
  1. **裏ストッパー下部の逃げ段差（`u = -2.05 mm`）による反時計回りピボット抜け**:
     - 薄鉄板下端（`v = 0.00 mm`）高さに約 `1.05 mm` の隙間が空いていたため、ホルダー下部が手前（`+u`）へ傾くだけで板バネをほとんど撓ませずに爪先端が `+1.5 〜 2.0 mm` 逃げてしまい、実質噛み込み量が `< 0.5 mm` まで減少していた。
  2. **前後開口幅（`11.25 mm`）および底面深さ（`v = -11.00 mm`）の過大マージン**:
     - 実機の総前後スパンは約 `10.15 mm`（約 `1.00 mm` 薄鉄板 ＋ 約 `1.95 mm` 前後クリアランス ＋ `φ7.20 mm` 丸パイプ）であり、開口 `11.25 mm` では前後に約 `1.1 mm`、底面 `-11.00 mm` では上下に約 `1.8 mm` の遊びが生じていた。
  3. **着座時の予圧ゼロ ＆ `45°` スロープによる滑り抜け**:
     - 押し上げ完了後に手を離すとホルダーが約 `1.8 mm` 沈んでバネ反力 `0 N` の緩んだ状態になり、さらに水平 `45°` 斜面が滑り台のように作用して下向き引き抜き耐力が約 `2.1 〜 3.0 kgf` に留まっていた。

### v3 での改善内容
1. **下部逃げ段差の全廃 ＆ 精密ゼロガタ J スロット化（開口 `11.25 mm → 10.50 mm`、底面 `-11.00 mm → -9.65 mm`）**:
   - 薄鉄板裏ストッパー壁（`STOPPER_FRONT_U = -1.08 mm`）の下部逃げ段差を全廃し、底面 `v = -9.65 mm` から上端付近 `v = +10.60 mm` まで **全面フラットの垂直密着壁** とすることで反時計回りピボット抜けを物理的に封じた（上端先端 `STOPPER_TOP_V = +11.40 mm` のみ `0.80 mm × 45°` 導入テーパーを付与し、差し込み深さも `+3.00 mm` 延長）。
   - 前壁を `J_FRONT_INNER_U = +9.42 mm` へ詰めて前後開口を **`10.50 mm`**（実機 `10.15 mm` に対し片側約 `0.17 mm` の精密嵌合、入口は `1.10 mm × 45°` ファンネル付き）とし、底面受け座も **`J_FLOOR_TOP_V = -9.65 mm`** へ `+1.35 mm` 引き上げて上下ガタを解消した（内側底コーナー2箇所に応力緩和 `R0.80 mm` フィレット付与）。
2. **水平 `35.0°` ディープフック座面 ＋ 常時クランプ予圧 ＋ ばね剛性強化（引き抜き耐力 約 `6.6 〜 9.4 kgf`）**:
   - フック爪先端を `LATCH_TIP_U = +5.80 mm`（v2 の `+6.70 mm` からさらに `0.90 mm` 奥、丸パイプ頂点 `+5.45 mm` 付近までカバー）へ伸ばし、噛み込み深さを **`3.25 mm`**（v2 比約 `1.5 倍`）へ拡大。
   - フック下面を水平から **`35.0°` の浅角ディープフック**（造形オーバーハング厳密 `55.0°`、サポート不要上限内）に変更し、かつ丸パイプが底面 `-9.65 mm` に着座した状態でも **`+0.55 mm`（約 `0.46 〜 0.66 kgf`）の常時クランプ予圧** が残り続ける高さ（`LATCH_TIP_V = -2.27 mm`）に設計。これにより装着完了瞬間から丸パイプを底面へ押さえつけ、薄鉄板裏へ引き寄せる **上下・前後ゼロガタ固定** を実現した。
   - ラッチ幅を `13.00 mm → 16.00 mm`、垂直ステム厚を `3.00 mm → 3.30 mm`（背面逃げポケット `5.75 mm`）へ強化し、押し込みクリック力を **PETG 約 `2.7 kgf`（`26.8 N`）/ PLA Matte 約 `3.1 kgf`（`30.0 N`）/ PLA 約 `3.9 kgf`（`38.3 N`）**、下向き引き抜き耐力を **約 `6.6 〜 9.4 kgf`（`64.5 〜 92.1 N`、ラケット重量の 20 倍以上）** へ約 3 倍以上に引き上げた（層間 Z 引張応力は最大 `15.6 MPa` 以下で安全）。

## 2026-11-11 (v2): 実機テスト結果に基づく丸パイプ前方2mmクリアランス配置修正 ＆ Z=0独立ロング板バネラッチ化

### 背景・実機テストでの判明事項
- v1 の事前嵌合テストピース（`steel_rack_tennis_racket_holder_fit_test.step`）を実機印刷してスチールラックへ当てたところ、**まったく嵌まらない**ことが判明した。
- 原因をユーザーと断面図で照合した結果、以下の **2点の設計不具合** を特定した：
  1. **丸パイプ前後位置の解釈逆転（`7.20 mm` のズレ）**:
     - 実機のラックは、棚板の垂直面（`u = 0.00 mm`）と丸パイプ奥面の間に **`2.00 mm` の前後クリアランス** が空いており、**`φ7.20 mm` 丸パイプ全体が板の垂直面より手前側（`u = +2.00 〜 +9.20 mm`、中心 `u = +5.60 mm`）** にある構造であった（v1 では「手前端が `+2.00 mm` で残り `5.20 mm` が棚板より奥に潜る `u = -5.20 〜 +2.00 mm`」と誤解していた）。
  2. **底面ブロック連続化によるCスナップの過剛性化**:
     - v1 ではスナップ爪の下側が底面ブロック（厚さ `5.7 mm` の塊）と直結していたため、実質的な片持ち梁スパンが確保されず手作業で弾性変形させられない硬さになっていた。またテストピースの前後向きも直感的に判別しづらかった。

### v2 での改善内容
1. **実機断面（`PIPE_CENTER_U = +5.60 mm`）への完全適合とストレートアップ直進装着化**:
   - 丸パイプ中心を `(u = +5.60 mm, v = -5.60 mm)` へ `7.20 mm` 前方修正。
   - 左右の剛体デュアル J フックが「薄鉄板の裏面（`u = -1.25 mm`）」と「丸パイプ手前（`u = +10.00 mm`）」を開口 `11.25 mm`（入口ガイド `12.85 mm`）で跨ぐ構造とし、**真下から傾けずに真っ直ぐ持ち上げるだけ** で薄鉄板と丸パイプを同時に捉える方式へ刷新（前後・上下クリアランスが `1.5 〜 2.5 mm` に変動しても無干渉で適合）。
2. **`Z = 0` 連続繊維・独立ロング板バネラッチ（押し込み力 約 `1.4 〜 2.0 kgf`）の新設**:
   - 中央ベイに、左右 `2.00 mm` の貫通分離スリットと背面 `5.00 mm` のたわみ逃げポケットで周囲の塊から完全に切り離した幅 `13.00 mm` の L 字ロング板バネを配置。
   - ビルドプレート `Z = 0` 上を水平に走る板厚 `1.80 mm`（`0.60 mm × 3`）× スパン `13.50 mm` の連続繊維リーフが主たわみを担うことで、押し込みクリック力を **PETG 約 `1.4 kgf` / PLA 約 `2.0 kgf`** に最適化しつつ、垂直ステムの層間引張応力を `< 13 MPa` に抑えて割れを防止。
   - 丸パイプ上肩（`+45°` 接線、造形オーバーハング厳密 `45.0°`・水平ブリッジゼロ）へカチッと乗り上げ、ラケット自重がかかるほどロックが深く締まるセルフロックを実現（上部リリースタブを手前に押せば簡単に取り外し可能）。
3. **本番と100%共通コアの新型テストピース（前後識別 V ノッチ付き）**:
   - `_build_mounting_core()` を本番モデルとテストピースで完全共通化し、テストピース（`35.00 × 27.00 × 28.80 mm`、約 `9 g` / 約 `14 分`）でも「左右対称 J フック ＋ 中央独立ロング板バネ」の実機スナップ感をそのまま検証可能にした。さらに手前側フロントスパイン（高さ `28.80 mm`、後ろ側ストッパーは `23.40 mm`）の上面中央に **`45°` V ノッチ** を刻み、前後・中心が一目でわかるように改善した。

## 2026-11-11 (v1): 初版設計・実装（2機種兼用 外抱えV字クレードル ＋ Cスナップ一体型デュアルJフック）

### 背景・ユーザー要件
- リビングのマットブラック・スチールラック（最上段の横桟）に、カバーなしの硬式テニスラケットをフラット（ガット面をラック前面と平行・ヘッド上向き）に気持ちよく掛けられるホルダーを作りたい。
- 下段にはお子様のおもちゃ等が収納されており、上方（棚板天面より上）へのラケットヘッドの飛び出しは問題ない。
- 以下の **2機種のテニスラケットを可能なら1つのモデルで兼用** したい（難しい場合のみ2バージョン作成）：
  1. ジュニア用 26インチ：**Wilson CLASH 26 V3.0**（`100 sq.in.` / `245 g` / フラットビーム `24.0 mm` 厚）
  2. 大人用 27インチ：**HEAD EXTREME MP 2026 (`233316`, G2)**（`100 sq.in.` / `300 g` / 可変ビーム `23 / 26 / 21 mm` 厚）

### 実機採寸・写真解析結果
- **スチールラック嵌合部（ノギス・定規実測 ＋ 裏面写真確認）**:
  - 棚板前垂れ（折り曲げフチ）縦高さ: **`18.1 mm`**、板厚 **約 `1.0 mm`** の薄い鉄板（下端の内側折り返しなし、裏側は高さ約 `17.0 mm` の中空懐空間）。
  - 水平丸パイプ（横桟）外径: **`φ7.20 mm`**（半径 `3.60 mm`）。
  - 棚板下端 〜 丸パイプ上端の上下隙間: **約 `2.0 mm`**。
  - 棚板前面 〜 丸パイプ手前端の前後段差: 丸パイプ手前端が **約 `2.0 mm` 手前** に突出（※v1時点ではパイプ中心 `u = -1.60 mm` と誤解釈し、v2にて前後クリアランス `2.0 mm` ＝ パイプ中心 `u = +5.60 mm` へ修正）。
- **テニスラケット2機種のスロート形状照合**:
  - **HEAD EXTREME MP 2026**（ユーザー実測値）: 三角穴下角での外幅 **約 `41 mm`**、横棒すぐ下での外幅 **約 `130 mm`**、三角穴縦内寸 **約 `99 mm`** → 片側テーパー角 **約 `24.2°`**。
  - **Wilson CLASH 26 V3.0**（全長 `660.4 mm` 基準の正面商品画像ピクセル校正値）: 三角穴下角での外幅 **約 `35 mm`**、横棒すぐ下での外幅 **約 `121 mm`**、三角穴縦内寸 **約 `99 mm`** → 片側テーパー角 **約 `23.5°`**。
  - 両ラケットのスロート片側テーパー角の差がわずか **`0.7°`** であるため、緩やかなクラウニング（太鼓R）付きの **1モデル完全兼用設計** を採用した。

### 設計上の判断と工夫
1. **3案比較からの「案1：外抱えV字クレードル型（ヘッド上向き）」選定**:
   - センター1本フック型（逆さま掛け・下段干渉）や二股ダブルピン型（ラケット未収納時の突起・前後揺れ）と比較し、上からスッと下ろすだけで自動調心して左右2辺で安定保持でき、未収納時も安全な丸みのある外観となる「外抱えV字クレードル型」を選定。
2. **2機種完全兼用クラウニングV字溝 ＆ 保護フィレット**:
   - 片側基準角 `24.0°`・溝深さ `26.50 mm` の左右受け面に `0.45 mm` 膨らむ太鼓クラウニング（`R350 mm` 相当）と全周保護フィレット（外周 `R3.0 mm`・ラケット接触部 `R1.8 mm`・上端導入面取り `C1.2 mm`）を付与した。
