# 履歴とプロンプト経緯

## 2026-06-28
- **豆腐文字対策 (CJKフォント登録)**:
  - Conda環境内のOCP (Open Cascade) のフォントマネージャが日本語フォントを検出できず、日本語文字が四角（豆腐文字）になる問題を修正。
  - PythonのOCP API (`Font_FontMgr`, `Font_SystemFont`) を使い、Macのシステムフォントパス（`/System/Library/Fonts/` 以下のヒラギノ角ゴシック、または `/System/Library/Fonts/Supplemental/` 以下の Arial Unicode）を動的に検出して登録するロジックを実装。
- **初版作成**:
  - アクリルマーカーの基本6色（セルリアンブルー、イエロー、オレンジ、コーラルレッド、マゼンタ、バイオレット）およびメタリック6色（オールドローズ、ローズゴールド、ブルー、ターコイズブルー、オレンジゴールド、ピンク）の色見本パレットを作成。
  - 基本6色を "BASIC"、メタリック6色を "METALLIC" として上下のセクションに分割してレイアウト。
  - 各色に12x12x0.4mmの塗布用凹みセルを配置。
  - 各セルの下に日本語（カタカナ）で色名を配置。Mac環境の `"Hiragino Kaku Gothic ProN"` フォントを指定。
  - 文字数（最大9文字）を考慮し、フォントサイズを `3.2mm`、セル間隔を `32.0mm` に設定して文字同士の重なりを回避。
  - テキスト部分とベースプレートを別パーツにしたアセンブリ（Assembly）として構築し、`acrylic_marker_palette3.step` を生成。
