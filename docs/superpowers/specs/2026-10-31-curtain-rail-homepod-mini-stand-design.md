# カーテンレール上用 HomePod mini 2 機械ロック式スタンド（Curtain Rail HomePod mini Stand）設計仕様書

## 1. 概要と目的

リビング後方の楕円（角丸）断面 C 型ダブルカーテンレール（厚さ `9.5 mm`・前後 2 本外寸スパン実測約 `66.8 mm`）の上に、Apple TV 4K サラウンド構成のリアスピーカーである **HomePod mini 2（第 2 世代、2026 年 10 月発売）** を安定・高音質・スマートに常設するための専用 1 パーツ機械ロック式スタンドを設計する。

両面テープ（アクリルゲルテープ）頼みの固定による夏場の熱クリープ剥離リスクや「ぷにぷに揺れ」を排除し、以下を同時に満たすことを目的とする。

- **壁穴ゼロ・工具最小限・物理的落下リスクゼロ**: 前後 2 本の C 型レール下角を外側から抱え込む「片手スナップ仮固定 ＋ `M3` ボルト 1 本デッドロック機構」により、高所（約 2 m）でも安全に装着でき、地震やカーテン開閉振動でも外れないこと。
- **カーテンランナー完全非干渉**: C 型レール底面中央のランナー走行溝（幅約 `6.0 mm`）を避け、レール外縁のみを保持することでカーテン開閉を一切妨げないこと。
- **音響影響の最小化**: 球体メッシュ側面およびデュアルパッシブラジエーターを覆う横ガードを一切設けず（`0 mm`）、底面の 360° アコースティックウェーブガイドが必要とする硬くフラットな境界反射面（ソリッド天板）のみを提供すること。
- **Bambu Lab P2S Combo（`256 × 256 × 256 mm`）＋ `0.6 mm` ノズル最適化**: 分割なしの 1 パーツ横向き一体造形・サポート材完全ゼロ（`0 g`）・一筆書き連続ループ積層で高強度かつ短時間に造形できること。

## 2. 対象機器・設置環境・手持ち金具の条件

### 2.1 HomePod mini 2（第 2 世代）

- **球体最大直径 × 高さ**: `97.9 mm × 84.3 mm`
- **重量**: `335 g`
- **底面シリコン足直径**: 約 `48.0 mm`（写真ピクセル比および筐体規格より算出）
- **ワイヤレス仕様**: Wi-Fi 6E (6GHz) / Bluetooth 6 / Thread / UWB（S10 SiP）
- **電源コード**: 本体下部背面から編み込み USB-C ケーブル（外径約 `3.5 〜 3.8 mm`）が引き出される構造

### 2.2 C 型ダブルカーテンレール（設置推奨位置：金属ダブルブラケットのすぐ左側）

- **レール断面（前後 2 本共通・楕円/角丸断面ステンレス C 型レール）**:
  - **高さ（厚み）**: **`9.5 mm`**（実測確定値）
  - **奥行（1 本幅）**: 約 **`17.5 mm`**（定規写真および中型 C 型規格値。側面が上下約 **`R3.2 mm`** の半円〜楕円状に丸まっており、底面中央に約 `6.0 mm` 幅のランナー走行溝が存在）
- **前後 2 本の配置（v1 嵌合テストピース実機ロック再現写真＋定規写真による校正値）**:
  - **前後 2 本跨ぎ外寸スパン（奥レール背面最大膨らみ部 〜 手前レール前面最大膨らみ部）**: 約 **`66.8 mm`**
  - **クランプ許容範囲**: 外寸スパン **`65.0 mm 〜 68.0 mm`** の範囲を微小しなりで無加工クランプ固定できること
- **壁面・周辺クリアランス**:
  - **白い本壁 〜 奥レール背面**: 約 `31.5 mm`（ブラケット左側の窓枠木枠が途切れたフラット区間、有効レール長 約 `146 mm`）
  - **ベージュ窓枠木枠前面 〜 奥レール背面**: 約 `18.0 mm`（ブラケット近傍）

### 2.3 使用締結金具（手持ち M3 アソートセット）

- **使用ボルト**: `M3 × 12 mm` 黒色酸化被膜 12.9 合金鋼 六角穴付きボルト × 1 本（頭径 `5.5 mm`・頭高 `3.0 mm`、予備として同セット内の `M3 × 16 mm` もそのまま使用可能）
- **使用ナット**: `M3` 六角ナット × 1 個（二面幅 `5.5 mm`・厚み `2.4 mm`）

## 3. 素材および製造環境

- **推奨フィラメント**: 非 CF の純粋な **`PETG`**（`Bambu PETG HF` / `Bambu PETG Basic` 等、または `ASA`）
  - 窓際・天井付近の高温環境（夏場・暖房時 `45 〜 55 ℃`）に耐える耐熱性（HDT 約 `70 ℃`）と耐クリープ性、および一体バネ爪に適したしなやかな弾性を備える。
  - 天井近く（約 2 m）に設置すると室内の Wi-Fi 6E ルーター・Apple TV 4K・手元の iPhone（UWB）がすべてスタンド斜め下方向に位置するため、導電性の炭素繊維を含む `PETG-CF` を避け、6GHz / UWB 電波減衰ゼロの純粋な `PETG` を採用する。
- **使用プリンター / ノズル**: Bambu Lab P2S Combo / `0.6 mm` ノズル
- **基準レイヤー高さ**: `0.30 mm`（積層方向の幅を `0.30 mm` の完全整数倍で設計）
- **サポート材**: なし（すべての形状をオーバーハング `45°` 以下で設計し、サポート材 `0 g` を達成）

## 4. 構造設計と各部寸法

### 4.1 造形向きと座標系定義（Bambu Studio インポート時基準）

スライサーにインポートしたままサポート無しで造形できるよう、**「設置時の右側面（金属ブラケット側端面）」をビルドプレート接地面（`Z = 0`）として寝かせた姿勢** をモデルの標準座標系とする。XY 平面においてはモデル全体のバウンディングボックス中心を原点 `(0, 0)` に配置する。

内部設計座標 `(u, v, z)` を以下のように定義する（最終出力時に `u → X`, `v → Y` へ平行移動して XY 原点中心へ配置）：

- **`u` 軸（設置時の奥 → 手前方向）**: 奥レールの背面突き当て位置を基準 `u = 0.0 mm` とし、室内手前側を `+u` とする。
- **`v` 軸（設置時の下 → 上方向）**: 前後 2 本のレール上面フラット面を基準 `v = 0.0 mm` とし、上方を `+v` とする。
- **`z` 軸（造形積層方向 ＝ 設置時の右 → 左方向）**: `z = 0.00 mm`（ブラケット側右端面）から `z = STAND_WIDTH = 66.00 mm`（`0.30 mm × 220 層`、白キャップ・電源コード側左端面）までとする。

この横向き配置により、奥側固定 C 字爪・天板ブリッジ・手前側一体バネ外爪・外側 `M3` ナット保持枠のすべてが **`XY` 平面内の一筆書き連続外周ループ** で造形され、層間剥離によるツメ破断リスクを構造的にゼロにする。

### 4.2 2段階レールロック断面プロファイル（`u-v` 断面、v2 楕円レール最適化版）

1. **レール上面連続受け座（ソリッド基準面 `v = 0.0 mm`）**:
   - `u = 0.0 mm` から `u = 63.0 mm` までを同一平面（`v = 0.0 mm`）の剛体受け座とする。
   - これにより、奥レール（`u ≈ 0.0 〜 17.5 mm`）の全面と手前レール（`u ≈ 49.3 〜 66.8 mm`）の上面フラット部全域が非変形のソリッド本体に直接面接触する。
   - レール噛み合い縦溝高さは `RAIL_SLOT_HEIGHT = 9.8 mm`（レール厚 `9.5 mm` ＋ 縦クリアランス `0.3 mm`、`v = -9.8 〜 0.0 mm`）とする。

2. **奥側 固定 C 字外爪（楕円受け凹Rクレードル、`u = -5.0 〜 +4.3 mm`）**:
   - **背面壁厚**: `REAR_WALL_THICKNESS = 5.0 mm`（`u = -5.0 〜 0.0 mm`、`v = -13.0 〜 +8.4 mm`）、上下内角に楕円側面に馴染む `R1.8 mm` の凹フィレットを設ける。
   - **底面回り込み爪**: `REAR_HOOK_LIP_DEPTH = 4.3 mm`（`u = 0.0 〜 +4.3 mm`）、厚み `HOOK_LIP_THICKNESS = 3.2 mm`（`v = -13.0 〜 -9.8 mm`）。楕円角の丸みを越えてレール底面フラット部を確実に抱え込みつつ、中央ランナー走行溝（`u ≈ 5.75 〜 11.75 mm`）と一切干渉しない。

3. **手前側 `PETG` 一体バネ外爪（片手スナップ仮固定 ＆ 微小しなりロックアーム）**:
   - **バネ根元リリーフ空間**: `u = 64.5 〜 67.6 mm` の天井を `v = +5.2 mm` まで掘り上げ、手前バネ爪が内側（`u = 65.0 mm` 位置）まで押し込まれても剛体受け座と干渉しないストローク空間を確保する。
   - **バネ腕断面**: 自由状態（ボルト緩め時）の内壁位置を `FRONT_FLEX_REST_U = 67.6 mm`（レール最大幅 `66.8 mm` に対し `+0.8 mm`）、肉厚を `FLEX_ARM_THICKNESS = 1.8 mm`（`0.6 mm × 3 周` の連続壁ループ、`u = 67.6 〜 69.4 mm`）、有効片持ち長を `18.2 mm`（`v = +5.2 mm` 〜 `-13.0 mm`）とする。
   - **底面スナップ爪**: `u = 67.6 mm` から内側へ `FRONT_HOOK_LIP_DEPTH = 3.6 mm`（先端 `u = 64.0 mm`、厚み `3.2 mm`、下内角凹 `R1.6 mm`）張り出し、下端内角に `2.0 mm` の `45°` スナップ導入テーパーを設ける。
   - **片手仮固定と微小しなりロック**: `66.8 mm` レールへの装着時、奥爪を引っ掛けて手前を上から押すと、バネ爪先端が外側の逃げ隙間（幅 `3.4 mm`、`u = 69.4 〜 72.8 mm`）へ約 `2.8 mm` 弾性変形してパチンと手前レール底面フラット部に噛み合い、ボルトを締める前から手を離しても落下しない仮固定状態となる。さらにボルト本締め時の内側しなり量は **約 `0.8 mm`（傾き `3°` 未満のほぼ垂直状態）** に抑えられ、長期樹脂クリープを防止する。
   - **ボルト受けパッド**: ボルト先端が当たる中央部のみ背面へ `+0.6 mm` 厚みを増し、深さ `0.8 mm` の円錐センタリング窪みを設けてボルト軸力を面で受け止める。

4. **手前外側 高剛性 `M3` デッドロック枠（`u = 72.8 〜 82.8 mm`）**:
   - 天板前端（`v = +5.2 〜 +8.4 mm`、肉厚 `3.2 mm` ソリッド橋）から下方 `v = -13.0 mm` まで垂下する肉厚 `10.0 mm` の高剛性アウターフレームとする。
   - **ボルト・ナット中心軸**: `v = -4.9 mm`（レール厚み `9.5 mm` の最大膨らみ中央高さ）、`z = 33.00 mm`（全幅中央。テストピースでは `z = 6.00 mm`）。
   - **`M3` 六角ナット埋め込みスロット（回転止め・サポート不要）**:
      - 位置: `u = 74.15 〜 76.80 mm`（厚み方向幅 `2.65 mm`、Z方向二面幅 `5.65 mm`、上端 `45°` 山形屋根リリーフ付き）。下端面（`v = -13.0 mm`）から差し込み自動で空回り防止となる。
   - **ボルト貫通穴・頭ザグリ穴**:
     - `φ3.4 mm` ボルト貫通穴（`+z` 頂部に `45°` ティアドロップ形状付与）。
     - 前面（`u = 82.8 mm`）から深さ `4.4 mm`（座面 `u = 78.4 mm`）・径 `φ6.6 mm`（ティアドロップ付き）の頭ザグリを設ける。
     - **`M3 × 12 mm` ボルト使用時の挙動**: ザグリ座面（`u = 78.4 mm`）から `66.8 mm` レールロック時のパッド窪み底（`u = 68.4 mm`）までがちょうど `10.0 mm` となり、ナット全山噛み合い・ボルト頭ほぼツライチ・さらに `2.0 mm` の増し締め余裕を確保する（`M3 × 16 mm` も使用可能）。

### 4.3 音響ミニマル天板と底面シリコン足浅溝

- **天板全体寸法**: 幅 `STAND_WIDTH = 66.00 mm` × 本体奥行 `87.8 mm`（`u = -5.0 〜 +82.8 mm`）、天面高さ `v = +8.4 mm`。
- **スピーカー載置中心**: **`(u_center, z_center) = (36.5 mm, 33.0 mm)`**
  - 前後レール中心（`u = 33.4 mm`）より `3.1 mm` 室内側に配置し、球体背面と白い本壁（`u = -31.5 mm`）の間に約 **`19.0 mm`** の空間を確保しつつ、浅溝上縁（`u = 10.25 〜 62.75 mm`）が 100% フル肉厚ソリッド反射床（`u ≤ 63.0 mm`）の直上に収まる。
- **底面シリコン足センタリング浅溝**:
  - 底面高さ `v = +6.9 mm`（レール上面との間に **`6.9 mm` 厚の 100% ソリッド反射床** を確保）、深さ **`1.5 mm`**、底面フラット径 **`φ49.5 mm`**、外周縁 **`45°` テーパー面取り**（天面開口径 `φ52.5 mm`）。

### 4.4 一体型 電源コード抜け止めクリップ（ストレインリリーフ）

- **配置位置**: 左側面（白キャップ側 `z = 56.0 〜 66.0 mm`、`z = 48.8 mm` から `45°` 傾斜ガセット接続）の奥レール背面下部（`u = -12.2 〜 -5.0 mm`）。
- **クリップ形状**: 内径 **`φ4.5 mm`**、背面導入スリット幅 **`2.9 mm`**。

## 6. パラメトリック設計と自動幾何検証項目

- すべての主要寸法・クリアランス・肉厚・角度をスクリプト冒頭の大文字定数として定義し、`unittest` により以下を自動検証する。
  1. 本番モデル・テストピースともに単一閉ソリッド（Valid Solid）であること。
  2. バウンディングボックスが `Z_min = 0.0 mm` に完全接地し、外寸が設計値（本番 `95.0 × 21.4 × 66.0 mm`、テストピース `87.8 × 21.4 × 12.0 mm`）であること。
  3. 楕円（角丸 `R3.2 mm`）断面を持つ前後 2 本の C 型レール（厚さ `9.5 mm`・幅 `17.5 mm`・外寸スパン `66.8 mm`）および中央ランナー走行空間（幅 `6.0 mm` ＋ 左右安全余裕 `1.0 mm`）と自由状態で干渉体積 `0` であり、かつ手前ツメ先端（`64.0 mm`）が `66.8 mm` レールに対して `2.5 mm` 以上のスナップ掛かり代を持つこと。
  4. `M3` ボルト穴・`M3` 六角ナットスロット（空回り防止込み）・天板シリコン足浅溝・ソリッド反射床・コードクリップ開口が設計通り形成され、STEP 出力・再読込後の体積が一致すること。
