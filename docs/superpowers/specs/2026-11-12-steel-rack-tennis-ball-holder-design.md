## 1. 背景と設計目的

マットブラックのスチールラック（天板端部が下に `18.1 mm` 折り曲げられた約 `1.0 mm` 厚の薄鉄板フチ ＋ 前方 `2.0 mm` クリアランス・下 `2.0 mm` に通る `φ7.2 mm` 水平丸パイプ）に対し、工具不要・ワンタッチでガタなく固定でき、硬式テニスボールを縦に最大4球スッキリ収納できる皿型ボールスタンドを設計する。

筒状ケースでは下の球が取り出しにくくなる課題を解消するため、**手前が大きく開いたC字リング皿を縦4段（`75.0 mm` 等間隔ピッチ）に配置**し、どの段のボールも上の皿に指が当たらず手前へサッと摘まみ出せる構造とする。また、1〜3段目は通常硬式球（基準 `φ67.0 mm`）に最適化しつつ、最上段（4段目）のみ連続2段凹面フレア座面とすることで、**通常球4個置き**にも**最上段への大きめレッドボール（`φ75〜80 mm`）1個置き**にも両対応させる。

---

## 2. 構造方式の選定（上向き1ピース一体造形タワーの採用理由）

伸びる向き（横桟から上向き vs 下向き）について構造工学および積層造形（Bambu Lab P2S CoreXY / 造形上限 `256 × 256 × 256 mm`）の観点から比較した結果、以下の理由により **「横桟から上方向へ立ち上がる分割なし1ピース一体造形タワー（樹脂全高 `246.00 mm`）」** を採用する。

1. **ジョイント（継ぎ目）ゼロによる最高剛性・ガタゼロ**:
   - 下向き配置では Z=0 連続繊維板バネとの兼ね合いで2ピース差し込み構造またはサポート併用が必要となり、接合クリアランス起因のガタや経年クリープが生じやすい。上向き1ピース一体造形であれば継手が一切なく、組立不要で永久に初期剛性を維持できる。
2. **Z=0 ワイドU字ベース接地による高層造形安定性**:
   - 第1段（#1）のC字リング皿下部スカートをそのまま `Z = 0.00 mm` ビルドプレートまで接地させることで、ベッド上に **横幅 `77.0 mm` × 奥行 `93.3 mm`** の広いU字フットプリントを形成。CoreXY方式（ベッドXY固定）の Bambu Lab P2S と相まって、ブリムなしでも全高 `246.00 mm` まで揺れゼロで安定造形できる。
3. **重力モーメントの自己倍力ロック作用**:
   - ボール4球（約 `230 g`）の荷重は丸パイプ中心（`u = +5.60 mm`）より手前（`u = +65.00 mm`）に作用するため、時計回りモーメントによって上部背面ストッパー（`u = -1.06 mm`）が薄鉄板フチ裏面（`u = -1.00 mm`）へ常に押し付けられ、荷重がかかるほど姿勢が安定する。

## 3. 主要寸法・ジオメトリ仕様

### 3.1 スチールラック取付コア（実機検証済み v4 ロック機構の100%継承）
- ラック実測基準:
  - 薄鉄板フチ: 前面 `u = 0.00 mm`、板厚基準 `1.05 mm`、高さ `v = 0.00 〜 +18.10 mm`
  - 水平丸パイプ: 外径 `φ7.20 mm`、中心 `(u = +5.60 mm, v = -5.60 mm)`
- 剛体デュアルJフック（全幅 `68.00 mm` / 左右各 `24.20 mm` 幅）:
  - 上部ストッパー壁 `u = -1.06 mm`、丸パイプ下半分専用背面受け座 `u = +1.62 mm`、前側ガイド内壁 `u = +9.32 mm`（下部パイプ専用ポケット幅 `7.70 mm`）、底面受け座 `v = -9.55 mm`
- 中央 Z=0 連続繊維ディープフック板バネ（幅 `16.00 mm`、左右スリット `1.80 mm`）:
  - リーフ厚 `1.80 mm`、ステム前面 `u = +8.95 mm`（厚 `3.60 mm`）、頂点越え深爪先端 `(u = +4.55 mm, v = -1.42 mm)`（常時クランプ予圧 `+0.75 mm`）、指掛けリリースタブ上端 `v = +9.60 mm`（`Z = 24.60 mm`）、背面逃げポケット `u = +12.55 〜 +21.90 mm`
- **フロント・リリース指入れアーチ窓**:
  - 第1段のボールを外した状態で手前から親指・人差し指を差し込んでリリースタブを引けるよう、中央スパインの `Z = 28.80 〜 73.00 mm`（幅 `26.00 mm`）に45°切妻屋根付きの指入れ兼肉抜きアーチ窓を設ける（2・3段目背後にも同様の45°切妻トラス窓を配置し、左右 `21.00 mm` 幅×`6.60 mm` 厚の縦柱2本と各皿背後の横梁で高剛性ラダーフレームを構成）。

### 3.2 4段C字リング皿とボール保持・取り出しクリアランス
- **造形全体高さ**: `Z = 0.00 〜 246.00 mm`（`0.60 mm × 410` — `0.20 mm` / `0.30 mm` レイヤー両対応、P2S上限 `256 mm` に対し `10.0 mm` 余裕）
- **ボール中心前後位置**: `U_BALL_CENTER = +65.00 mm`（背面スパイン前面 `u = +28.50 mm` から `36.50 mm` 前方）
- **上下等間隔ピッチ**: `TIER_PITCH_Z = 74.40 mm`（`0.60 mm × 124`）
  - **#1〜#3段（通常硬式球 `φ65.4〜68.6 mm` / 基準 `φ67.0 mm` 専用座）**:
    - 座面下端 `Z = 12.60, 87.00, 161.40 mm` ／ リング上端 `Z = 18.60, 93.00, 167.40 mm`（リング座面高 `6.00 mm`）
    - 内周テーパー座面: 下端半径 `25.30 mm`（`φ50.6 mm`）→ 上端半径 `29.80 mm`（`φ59.6 mm`）。基準 `φ67.0 mm` 球が `r = 26.80 mm` で滑らかに接線着座し、球中心は `Z = 34.70, 109.10, 183.50 mm`（隣接ボール間の純粋上下隙間 `7.40 mm`）となる。
    - リング外半径 `R_out = 38.50 mm`（横幅 `77.00 mm`）、手前オープン開口幅 `45.00 mm`（`|x| <= 22.50 mm`、手前端 `u = +89.50 mm`、先端 `R2.00 mm` 保護丸め）。ボールは深さ約 `9 mm` のポケットに安定保持され、指で約 `9〜10 mm` 持ち上げるだけで手前へスムーズに取り出せる。
  - **#4段（最上段：通常球 `φ67 mm` ＆ レッドボール `φ75〜80 mm` 兼用の連続2段凹面座）**:
    - 座面下端 `Z = 235.80 mm` → 中間遷移 `Z = 240.40 mm` → リング上端 `Z = 246.00 mm`（全高 `246.00 mm` で完結し、4球目の上部は `Z > 246 mm` の開放空間へ出るため造形高さを圧迫しない）。
    - 下段内座（`Z = 235.80 〜 240.40 mm`）: `r = 24.80 → 28.80 mm`（通常 `φ67.0 mm` 球が `r = 25.28 mm` で接線着座、球中心 `Z = 258.33 mm`、第3段球との上下隙間 `7.83 mm`）。
    - 上段外フレア座（`Z = 240.40 〜 246.00 mm`）: 段差角のない連続凹面として `r = 28.80 → 33.47 mm` へ拡大。レッドフェルト球（`φ75.0 mm`）は `r = 28.81 mm`（球中心 `Z = 264.41 mm`）、レッドスポンジ球（`φ80.0 mm`）は `r = 30.73 mm`（球中心 `Z = 268.32 mm`）でいずれも接線着座して安定保持される。
    - リング外半径 `R_out_4 = 41.50 mm`（横幅 `83.00 mm`）、手前オープン開口幅 `45.00 mm`（`|x| <= 22.50 mm`、手前端 `u = +94.50 mm`）。

### 3.3 完全サポートフリー（全オーバーハング45°以下）＆ 下段ボール非干渉構造
- **#1段**: 下部スカートを `Z = 0.00 mm` まで直下ろしし、サポート不要かつ超ワイドなベッド接地面を形成（中央 `φ50 mm` 穴と手前 `45 mm` 開口は貫通させ、#1ボール下端 `Z = +1.11 mm` の非接触を保証）。
- **#2〜#4段**:
  1. 背面スパイン（`u = +28.50 mm`）から手前端へ向かって **45.0° でせり上がる下部傾斜面** でC字アームの下面を支持。
  2. 直下のボール中心 `(0, +65.00, Z_ball_prev)` を基準とする **半径 `38.50 mm`（球面から全方向 `+5.0 mm` クリアランス）＋ 上部45.0°ティアドロップ円錐ドーム** をくり抜くことで、下段ボールとの干渉ゼロと全下面オーバーハング `<= 45.0°`（浮島ゼロ・ブリッジゼロ）を同時に成立させる。
