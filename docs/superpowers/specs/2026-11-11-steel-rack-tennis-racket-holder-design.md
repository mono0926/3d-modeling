# スチールラック用 テニスラケット掛け（Steel Rack Tennis Racket Holder）設計仕様書（v3 高保持タイトロック版）

## 1. 概要と目的

マットブラックのスチールラック（天板端部が下に `18.1 mm` 折り曲げられた約 `1.0 mm` 厚スチール棚板 ＋ その垂直前面から **`2.0 mm` 手前のクリアランス** を空け、下端から **`2.0 mm` 下** に配置された `φ7.2 mm` 水平丸パイプ）に対し、カバーなしの硬式テニスラケット 2 機種（ジュニア用 **Wilson CLASH 26 V3.0** および大人用 **HEAD EXTREME MP 2026**）を **1 つのホルダーで兼用** し、ラック面に沿ってフラット（ヘッド上向き）に気持ちよく縦掛けできる専用ホルダーを設計する。

以下を同時に達成することを目的とする。

- **ネジ・テープ不要のストレートアップ装着 ＆ ガタつきゼロ・常時予圧ディープフック構造（v3）**: 左右の精密剛体 J フックが「約 `1.0 mm` 厚スチール棚板フチの裏面（`u = -1.08 mm`、下部逃げ段差なしの全面垂直壁）」と「前方 `φ7.2 mm` 丸パイプの手前（`u = +9.42 mm`、開口 `10.50 mm`）」および「丸パイプ底面（`v = -9.65 mm`）」を精密に受け止め、中央に完全独立配置した **`Z = 0` 連続繊維ロング板バネラッチ（幅 `16.00 mm`）** が丸パイプ頂点付近（`u = +5.80 mm`、噛み込み深さ `3.25 mm`）へ水平 `35.0°` のディープフック座面で「カチッ」と深く噛み込む。着座後も **`+0.55 mm`（約 `0.46 〜 0.66 kgf`）の常時クランプ予圧** で丸パイプを底面受けへ押さえ続けるため、上下・前後のガタつきがゼロとなり、引き抜き耐力 **約 `6.6 〜 9.4 kgf`（ラケット重量の 20 倍以上）** で容易に脱落しない高保持ロックを実現する（棚板上面 `v = +18.1 mm` への出っ張りも完全ゼロ）。
- **狭い隙間（約 `2.0 mm`）を通さず直進装着 ＆ リリースタブによる着脱性両立**: 板の垂直面と丸パイプの間の狭い `2.0 mm` 隙間には一切パーツを通さず真下から真っ直ぐ押し上げるだけで装着でき、取り外す際は上部のリリースタブ（`v = +6.60 mm`）を指先で手前ポケット側へ引くことで安全に解除できること。
- **26 インチジュニア用 ＆ 27 インチ大人用の 1 モデル完全兼用**: 実測・公式仕様より両ラケットのスロート片側テーパー角が `23.5°` と `24.2°`（差わずか `0.7°`）、フレーム厚が `24.0 mm` と `21.0 〜 26.0 mm` である特性を活かし、緩やかな太鼓 R（クラウニング）付きの `24.0°` 外抱え V 字クレードルとすることで、上からスッと下ろすだけでどちらのラケットも自動調心してグラつきなく保持できること。
- **Bambu Lab P2S Combo でのサポート材・ブリッジ完全ゼロ一体造形**: 設置時の水平フラット底面（`v = -15.00 mm`）をビルドプレート（`Z = 0`）にベタ置きする 1 ピース一体造形とし、すべてのオーバーハング角を `55.0°` 以下（水平ブリッジゼロ）に制御してサポート材 `0 g` で美しく出力できること。

## 2. 対象環境・ラケット仕様（実測値・v2 実機装着写真校正済み）

### 2.1 スチールラック嵌合部（ユーザー実測値 ＋ 実機装着写真ピクセル校正確認済み）

基準座標 `(u, v)` として、スチール棚板前面の外側垂直面を **`u = 0.00 mm`**（室内手前側を `+u`、棚奥側を `-u`）、棚板前垂れ（フチ）の下端を **`v = 0.00 mm`**（上方を `+v`、下方を `-v`）と定義する。

- **棚板前垂れ（スチール折り曲げ垂直面）**:
  - 縦高さ: **`18.1 mm`**（`v = 0.00 〜 +18.10 mm`、天板上面が `v = +18.10 mm`）
  - 板厚: **約 `1.00 mm`** の薄い鉄板（内面側に折り返しなし。裏側 `u < -1.05 mm, v = 0.00 〜 +17.00 mm` は高さ約 `17 mm` の中空懐空間）
- **水平丸パイプ（横桟）**:
  - 外径: **`φ7.20 mm`**（半径 `3.60 mm`）
  - 前後クリアランス: 棚板の垂直面（`u = 0.00 mm`）から丸パイプ奥面まで **約 `1.95 〜 2.00 mm`** の空間があり、**丸パイプ全体が垂直面より手前側**に配置（実機総前後スパン＝薄鉄板 `1.00 mm` ＋ 隙間 `1.95 mm` ＋ 丸パイプ `7.20 mm` ＝ **約 `10.15 mm`**、公称パイプ中心 **`u = +5.60 mm`**）
  - 上下クリアランス: 棚板下端（`v = 0.00 mm`）から丸パイプ上端まで **約 `2.00 mm`** の空間（パイプ上端 `v = -2.00 mm`、中心 **`v = -5.60 mm`**、下端 `v = -9.20 mm`）

### 2.2 対象テニスラケット（2 機種兼用）

1. **HEAD EXTREME MP 2026（品番: `233316` / 大人用 27.0 インチ G2）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `300 g`（ガット張り上げ時 約 `315 〜 320 g`）
   - フレーム前後厚（公式仕様）: **`23 / 26 / 21 mm`**（先端 `23 mm` / フェイス肩部最大 `26 mm` / スロート・シャフト部 `21 mm`）
   - スロート実測寸法（ユーザー計測値）:
     - 三角穴の下角高さでの左右外幅: **約 `41 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `130 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((130 - 41) / (2 \times 99)) \approx \mathbf{24.2^\circ}$
2. **Wilson CLASH 26 V3.0（ジュニア用 26.0 インチ）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `245 g`（ガット張り上げ時 約 `260 g`）
   - フレーム前後厚（公式仕様）: **`24.0 - 24.0 - 24.0 mm`**（フラットビーム `24.0 mm`）
   - スロート寸法（全長 `660.4 mm` 基準の正面商品画像ピクセル校正値）:
     - 三角穴の下角高さでの左右外幅: **約 `35 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `121 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((121 - 35) / (2 \times 99)) \approx \mathbf{23.5^\circ}$

## 3. アプローチの比較と選定経緯

1. **案 1（採用）：外抱え V 字クレードル型（ヘッド上向き）**
   - スロート外側の V 字テーパーを左右の斜めガイドと手前の返しリップで抱え込む方式。上から下ろすだけで自然にセンターへ収まり、左右 2 辺を面で受けるため揺れにくく、未収納時もツノ状の突起が出ず安全性が高い。
2. **案 2（不採用）：センター 1 本フック型（三角穴掛け・ヘッド下向き）**
   - 逆さま掛けの見栄えになるうえ、丸パイプから下へ約 `55 〜 60 cm` 垂れ下がり下段の収納物と干渉しやすい。
3. **案 3（不採用）：二股ダブルピン型（ヘッド上向き）**
   - 未収納時に 2 本のピンが手前へ突き出し、点支持に近いため案 1 より前後に傾きやすい。

## 4. 詳細構造設計（v3 精密ゼロガタ・高保持タイトロック設計）

### 4.1 素材・造形ピッチ最適化

- **推奨フィラメント**: **マットブラック系の `PETG` または `PLA Matte / PLA Tough`**（着座後の常時クランプ予圧に対する長期耐クリープ性と高い靭性の観点から **`PETG`（Bambu PETG HF / Matte 等）を第一推奨**、垂直ステムの層間 Z 引張応力を最大 `15.6 MPa` 以下に抑制しているため PLA 系でも割れずに使用可能）。
- **レイヤー高さ両対応設計**: 全高 `56.40 mm`（`0.60 × 94`）、テストピース高 `28.80 mm`（`0.60 × 48`）、底面板バネ厚 `1.80 mm`（`0.60 × 3`）と主要高さをすべて **`0.60 mm` の整数倍** で設計し、`0.20 mm` レイヤーと `0.30 mm` レイヤーの両方に端数なく対応する。

### 4.2 ラック固定機構：「精密ゼロガタ剛体デュアル J フック ＋ 常時予圧 `35°` ディープフック板バネ」

1. **ピボット抜けを完全阻止する精密ゼロガタ剛体デュアル J フック**:
   - 左右 `x = -28.00 〜 -9.80 mm` および `+9.80 〜 +28.00 mm`（各幅 `18.20 mm`、計 `36.40 mm` 幅、リアアーム肉厚 `4.32 mm`）に高剛性なコの字 J フックを配置。
   - **全面密着裏ストッパー壁（`STOPPER_FRONT_U = -1.08 mm`）**: 下部逃げ段差を設けず、底面 `v = -9.65 mm` から `v = +10.60 mm` まで一直線の垂直壁とすることで、薄鉄板下端（`v = 0.00 mm`）を支点とした反時計回りピボット抜けを物理的にゼロ化する（上端先端 `STOPPER_TOP_V = +11.40 mm` のみ `0.80 mm × 45°` の導入面取りを付与）。
   - **精密前後開口 `10.50 mm` ＆ 底面受け座 `v = -9.65 mm`**: 前側ガイド内壁を **`J_FRONT_INNER_U = +9.42 mm`**（上端入口は `1.10 mm × 45°` 導入ファンネル付き）として実機総スパン約 `10.15 mm` に対し片側約 `0.17 mm` のタイトな案内を実現し、底面受け座を **`J_FLOOR_TOP_V = -9.65 mm`**（内側コーナー `R0.80 mm` フィレット付き）へ引き上げて上下方向の遊びを解消する。
2. **完全分離された `Z = 0` 連続繊維・常時予圧 `35°` ディープフック板バネラッチ**:
   - 中央ベイ（`x = -9.80 〜 +9.80 mm`）内に、左右 **`1.80 mm` の貫通分離スリット** と背面 **`5.75 mm` のたわみ逃げポケット** で周囲から完全に切り離した幅 **`16.00 mm`** の L 字ロング板バネを配置。
   - 背面下部クロスバー（`u = -5.40 〜 -2.70 mm`）を固定端とし、ビルドプレート `Z = 0` 上を水平に伸びる **板厚 `1.80 mm` × 有効スパン `13.50 mm` の連続繊維リーフ** と **肉厚 `3.30 mm` の高剛性垂直ステム** で構成する。
   - 爪先端を **`LATCH_TIP_U = +5.80 mm, LATCH_TIP_V = -2.27 mm`** まで深く伸ばし（噛み込み深さ **`3.25 mm`**）、下面を水平から **`35.0°` の浅角ディープフック座面**（造形オーバーハング厳密 `55.0°`）とすることで：
     - 押し込みクリック力（`3.25 mm` たわみ時）: **PETG `26.8 N`（`2.73 kgf`）/ PLA Matte `30.0 N`（`3.06 kgf`）/ PLA `38.3 N`（`3.91 kgf`）**（垂直ステム層間 Z 引張応力は `10.9 〜 15.6 MPa` で安全圏内）
     - 着座完了時の常時クランプ予圧（`+0.55 mm` たわみ残し）: **約 `0.46 〜 0.66 kgf`（`4.5 〜 6.5 N`）** で丸パイプを常時底面 `-9.65 mm` へ押さえつけ、ガタつきを完全解消
     - 下向き引き抜き耐力（摩擦係数 `μ = 0.22` 時、倍率 `2.40×`）: **PETG `64.5 N`（`6.57 kgf`）/ PLA Matte `72.1 N`（`7.35 kgf`）/ PLA `92.1 N`（`9.39 kgf`）** とラケット重量の **20 倍以上** の保持力を発揮する。

### 4.3 2 機種兼用・外抱え V 字クレードル設計

- **クレードル位置と棚板クリアランス**: 逃げポケット後方の剛体フロントスパイン兼クレードル背板を `u = +18.20 〜 +21.80 mm` に配置し、ラケット受け溝を **`u = +21.80 〜 +48.30 mm`（溝深さ `26.50 mm`）**、手前返しリップ外端を `u = +52.80 mm` とする。これにより最大厚 `26.0 mm` 肩部でも棚板前面（`u = 0.00 mm`）から **`22.0 mm` 以上**、丸パイプ手前端（`u = +9.20 mm`）からも **`12.8 mm` 以上** 離れ、出し入れ時の接触傷を 100% 防止する。
- **V 字受け溝・クラウニング・保護 R**: 底面内幅 `52.00 mm`、片側基準テーパー角 `24.0°`、中央 `0.45 mm` 凸の太鼓クラウニング曲面（`R350 mm` 相当）、外周 `R3.0 mm` / ラケット接触部 `R1.8 mm` フィレット / 上端 `C1.2 mm` 導入面取りを備える。

## 6. 自動幾何・予圧・ばね力学検証項目（TDD / `unittest` 全 7 項目）

1. 丸パイプ前方配置（`PIPE_CENTER_U = +5.60 mm`）定数、タイト化された J スロット幅（`10.50 mm`）・底面高さ（`-9.65 mm`）・ストッパー高さ（`+11.40 mm`）、単一閉ソリッド（`is_valid`）、`Z = 0` 完全接地、XY 原点中心、`0.60 mm` 整数倍高さの検証。
2. 薄鉄板下端 `v = 0.00 mm` 高さでのピボット抜け防止壁の検証、および実機公差 4 条件すべてで剛体 J フックが棚板・パイプと無干渉で着座しつつ、ディープフック噛み込み量 `>= 3.00 mm` かつ着座時の常時クランプ予圧 `+0.20 〜 +1.00 mm` を維持すること。
3. 除外点なしの全 3D ブーリアン検証により、剛体フレームが真下（`dv = -24 mm`）から傾き `0°` のまま着座位置まで無干渉で直進進入できること。
4. 中央板バネの左右分離スリット・背面 `5.75 mm` ポケットが完全貫通空間であり、Castigliano エネルギー法による押し込みクリック力（`24 〜 50 N`）、引き抜き耐力 **`>= 60 N`（`> 6.1 kgf`）**、および層間 Z 引張応力 `< 17.5 MPa` をすべて満たすこと。
5. `CLASH 26 V3.0` と `HEAD EXTREME MP 2026` の双方が V 字溝に安定着座し、棚板・丸パイプから十分なクリアランスを保つこと。
6. `Z > 0.15 mm` の全面がサポート不要オーバーハング上限（`<= 55.0°`）に収まり、STEP 入出力が正常に往復できること。
7. ラケット接触部の保護フィレットおよびテストピース前後の高さ差（手前 V ノッチ側 `28.80 mm` / 棚裏ストッパー側 `26.40 mm`）による前後識別性の検証。
