# スチールラック用 テニスラケット掛け（Steel Rack Tennis Racket Holder）設計仕様書

## 1. 概要と目的

マットブラックのスチールラック（天板端部が下に `18.1 mm` 折り曲げられた約 `1.0 mm` 厚スチール棚板 ＋ その約 `2.0 mm` 下・約 `2.0 mm` 手前に配置された `φ7.2 mm` 水平丸パイプ）に対し、カバーなしの硬式テニスラケット 2 機種（ジュニア用 **Wilson CLASH 26 V3.0** および大人用 **HEAD EXTREME MP 2026**）を **1 つのホルダーで兼用** し、ラック面に沿ってフラット（ヘッド上向き）に気持ちよく縦掛けできる専用ホルダーを設計する。

以下を同時に達成することを目的とする。

- **ネジ・テープ不要のワンタッチ装着 ＆ お辞儀ゼロの 3 点圧縮セルフロック構造**: 丸パイプ（`φ7.2 mm`）単体へのクリップではラケット荷重のモーメントで手前に回転してしまう課題を解決するため、丸パイプの下〜裏から回り込んで **「約 `1.0 mm` 厚スチール棚板フチの裏面」と「`φ7.2 mm` 丸パイプの上奥（`+118°`）〜下前（`-22°`）」の 3 箇所を同時に噛み合わせる C スナップ一体型デュアル J フック機構** を採用する。ラケット自重がかかるほど 3 点の圧縮反力でロックが締まる静力学的セルフロック構造としつつ、棚板上面（`v = +18.1 mm`）への出っ張りを完全ゼロにする。
- **狭い隙間公差（約 `2.0 mm`）に依存しない確実な嵌合**: 丸パイプと棚板下端の狭い隙間（約 `2.0 mm`）にはパーツを一切通さず、丸パイプの下方から軽く傾けて（約 `20°〜30°`）裏側懐空間へ回し込み、最後の `0.25 mm` だけ丸パイプへパチンとスナップインする設計とすることで、溶接・組立個体差により隙間が `1.2 〜 3.5 mm` に変動しても干渉せず確実に装着できること。
- **26 インチジュニア用 ＆ 27 インチ大人用の 1 モデル完全兼用**: 実測・公式仕様より両ラケットのスロート片側テーパー角が `23.5°` と `24.2°`（差わずか `0.7°`）、フレーム厚が `24.0 mm` と `21.0 〜 26.0 mm` である特性を活かし、緩やかな太鼓 R（クラウニング）付きの `24.0°` 外抱え V 字クレードルとすることで、上からスッと下ろすだけでどちらのラケットも自動調心してグラつきなく保持できること。
- **Bambu Lab P2S Combo でのサポート材完全ゼロ一体造形**: 設置時の水平フラット底面（`v = -15.00 mm`）をビルドプレート（`Z = 0`）にベタ置きする 1 ピース一体造形とし、すべてのオーバーハング角を `45.0°` 以下に制御してサポート材 `0 g` で美しく出力できること。

## 2. 対象環境・ラケット仕様（実測値および公式仕様）

### 2.1 スチールラック嵌合部（ユーザー実測値・裏側写真確認済み）

基準座標 `(u, v)` として、スチール棚板前面の外側垂直面を **`u = 0.00 mm`**（室内手前側を `+u`、棚奥側を `-u`）、棚板前垂れ（フチ）の下端を **`v = 0.00 mm`**（上方を `+v`、下方を `-v`）と定義する。

- **棚板前垂れ（スチール折り曲げフチ）**:
  - 縦高さ: **`18.1 mm`**（`v = 0.00 〜 +18.10 mm`、天板上面が `v = +18.10 mm`）
  - 板厚: **約 `1.0 mm`** の薄い鉄板（内面側に折り返しなし。公差を見込み設計上の鉄板領域を `u = -1.15 〜 0.00 mm` とし、その裏側 `u < -1.15 mm, v = 0.00 〜 +17.00 mm` は高さ約 `17 mm` の中空懐空間）
- **水平丸パイプ（横桟）**:
  - 外径: **`φ7.20 mm`**（半径 `3.60 mm`）
  - 上下隙間: 棚板下端（`v = 0.00 mm`）から丸パイプ上端まで **約 `2.0 mm`**（パイプ上端 `v = -2.00 mm`、中心 `v = -5.60 mm`、下端 `v = -9.20 mm`）
  - 前後段差: 棚板前面（`u = 0.00 mm`）より丸パイプ手前端が **約 `2.0 mm` 手前**（パイプ手前端 `u = +2.00 mm`、中心 `u = -1.60 mm`、奥端 `u = -5.20 mm`）

### 2.2 対象テニスラケット（2 機種兼用）

1. **HEAD EXTREME MP 2026（品番: `233316` / 大人用 27.0 インチ G2）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `300 g`（ガット張り上げ時 約 `315 〜 320 g`）
   - フレーム前後厚（公式仕様）: **`23 / 26 / 21 mm`**（先端 `23 mm` / フェイス肩部最大 `26 mm` / スロート・シャフト部 `21 mm`）
   - スロート実測寸法（ユーザー計測値）:
     - 三角穴の下角高さでの左右外幅: **約 `41 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `130 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((130 - 41) / (2 \times 99)) \approx \mathbf{24.2^\circ}$
2. **Wilson CLASH 26 V3.0（ジュニア用 26.0 インチ）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `245 g`（ガット張り上げ時 約 `260 g`）
   - フレーム前後厚（公式仕様）: **`24.0 - 24.0 - 24.0 mm`**（フラットビーム `24.0 mm`）
   - スロート寸法（全長 `660.4 mm` 基準の正面商品画像ピクセル校正値）:
     - 三角穴の下角高さでの左右外幅: **約 `35 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `121 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((121 - 35) / (2 \times 99)) \approx \mathbf{23.5^\circ}$

## 3. アプローチの比較と選定経緯

ユーザーとの検討において、以下の 3 つのアプローチを比較した。

1. **案 1（採用）：外抱え V 字クレードル型（ヘッド上向き）**
   - スロート外側の V 字テーパーを左右の斜めガイドと手前の返しリップで抱え込む方式。
   - **利点**: 上から下ろすだけで自然にセンターへ収まり、左右 2 辺を面で受けるためヘッド上向きでも揺れにくい。ラケットを外している時もツノ状の鋭い突起が手前に出ないため、下段におもちゃがある環境でも見た目・安全性ともに優れる。
   - **トレードオフ**: 横幅が約 `118 mm` となるが、ラック横幅に対して十分コンパクトに収まる。
2. **案 2（不採用）：センター 1 本フック型（三角穴掛け・ヘッド下向き）**
   - ホルダー幅は最小（約 `40 mm`）になるが、逆さま掛けの見栄えになるうえ、丸パイプから下へ約 `55 〜 60 cm` 垂れ下がり下段の収納物と干渉しやすい。
3. **案 3（不採用）：二股ダブルピン型（ヘッド上向き）**
   - シンプルだが、ラケットを外している時に 2 本のピンが手前へ突き出し、点支持に近いため案 1 より前後に傾きやすい。

以上より、出し入れの心地よさ・安定感・安全性のバランスが最も高い **案 1（外抱え V 字クレードル型）** をユーザーが選定した。なお、上方向へのヘッドの飛び出し（棚板天面より上への突出）は問題ないこともユーザー確認済みである。

## 4. 詳細構造設計（設計者決定事項を含む）

以下の具体的な寸法・スナップ剛性・造形ピッチ設計は、上記要件を満たすための設計者側の決定（Engineering Call）である。

### 4.1 素材・造形ピッチ最適化

- **推奨フィラメント**: **マットブラック系の `PETG` または `PLA Tough / PLA Matte`**（C スナップ着脱時の靭性と長期耐クリープ性の観点から **`PETG`（Bambu PETG HF / Matte 等）を第一推奨**、最大ひずみ約 `0.33%` の極低ひずみ設計のため PLA 系でも割れずに使用可能）。
- **レイヤー高さ両対応設計**: 主要な高さ寸法を **`0.60 mm` の整数倍** を基準に設計し、`0.4 mm` ノズル（`0.20 mm` レイヤー）と `0.6 mm` ノズル（`0.30 mm` レイヤー）のどちらでも端数なくスライス可能とする。
- **造形姿勢**: 設置時の底面（`v = -15.00 mm`）をビルドプレート **`Z = 0.00 mm`** に一致させ、XY バウンディングボックス中心を原点 `(0, 0)` に配置して出力する。

### 4.2 背面ラック固定機構：「C スナップ一体型デュアル J フック（3 点圧縮セルフロック）」

細い別体バネ爪に常時荷重を負担させるのではなく、高耐久な左右 1 ペアの **C スナップ一体型 J フック**（`x = -28.00 〜 -10.00 mm` および `+10.00 〜 +28.00 mm`、各幅 **`18.00 mm` × 2 本 ＝ 合計幅 `36.00 mm`**、中央 `20.00 mm` 開放）によって、心地よいスナップ着脱と高剛性な 3 点圧縮セルフロックを単一構造で両立する。

1. **`220°` 抱え込み C スナップ・パイプサドル**:
   - パイプ中心 `(u = -1.60, v = -5.60)`（外径 `φ7.20 mm`）に対し、クリアランス半径 **`R_s = 3.70 mm`（内径 `φ7.40 mm`）** で上奥 **`+118°`**（`u = -3.34, v = -2.33`）から背面 `180°`・底面 `-90°` を経て下前 **`-22°`**（`u = +1.83, v = -6.99`）までの **`220°`** を抱え込む。
   - `+118°` 端と `-22°` 端の開口弦長は **`6.95 mm`** であり、`φ7.20 mm` 丸パイプに対して **`0.25 mm` の微小弾性スナップ干渉** を持つ（先端に導入 R 付き）。
   - パイプ下方を通る U アーム肉厚を **`3.60 mm`**（背面ステム `u = -9.20 〜 -5.30 mm`、下部ブリッジ `v = -15.00 〜 -9.30 mm` のうちパイプ直下弾性部 `3.60 mm` 厚）にチューニングすることで、2 本合計の押し込みクリック力を **約 `2.5 〜 3.0 kgf`**（両手親指で気持ちよく「パチン」と嵌まる力）、着脱時の最大曲げひずみを **約 `0.33%`**（PETG 降伏ひずみの `1/10` 以下）、`320 g` ラケット積載時の弾性たわみを **`0.1 mm` 未満** に抑える。
2. **棚板フチ裏ストッパー爪と 3 点圧縮セルフロック**:
   - パイプ上奥（`+118°`）から **`68°` 以上の急勾配（造形オーバーハング `22°` 以下）** で立ち上がり、`v = +3.50 〜 +7.80 mm` において前端 **`u = -1.35 mm`** に位置するストッパー面を形成する。
   - **静力学的セルフロックの成立**: ラケット荷重 `(0, -W)` による時計回りモーメントは、①棚板フチ裏面（`u ≈ -1.15 mm`）からの後ろ向き圧縮反力、②丸パイプ上奥 `+118°` からの斜め上向き圧縮反力（約 `2.55 W`）、③丸パイプ下前 `-22°` からの前向き圧縮反力（約 `3.34 W`）の **3 点すべてが純圧縮（`> 0`）** となって釣り合うため、自重による滑り出し・お辞儀回転が完全に阻止される。またラケットを真上に持ち上げる際も `220°` の C スナップ保持力（約 `2.5 〜 3.0 kgf` 相当）によりホルダーが一緒に外れない。
3. **無干渉アプローチ経路（SE(2) 運動学確認済み）**:
   - ストッパー爪下前端 `(u = -1.35, v = +3.50)` と前方クレードル背板後面 `(u = +6.30)` の間隔は **`7.65 mm`（`> φ7.20 mm` パイプ径）** 確保されている。
   - これにより、ホルダーを丸パイプの下方から軽く傾けて（最大約 `20°〜30°`）ストッパー爪をパイプ裏の懐空間へ無干渉（変形 `0.00 mm`）で潜り込ませ、最後に前へ起こして `0.25 mm` だけパイプへスナップインするだけで装着が完了する（クレードル上端も棚板と一切干渉しない）。

### 4.3 2 機種兼用・外抱え V 字クレードル設計

1. **パイプ通過開口と棚板擦れ防止を両立する背板配置（`u = +6.30 〜 +10.50 mm`）**:
   - クレードル背板を **`u = +6.30 〜 +10.50 mm`（肉厚 `4.20 mm`）** に配置し、ラケット背面を受けるクレードル内壁を **`u = +10.50 mm`**（棚板前面 `u = 0.00 mm` から `10.50 mm` 手前）とする。
   - これにより `φ7.20 mm` パイプの通過開口（`7.65 mm`）を全幅にわたり確保しつつ、`HEAD EXTREME MP 2026` の最大厚フェイス肩部（`26.0 mm`、スロート `21.0 mm` より片側 `+2.50 mm` 張り出し）に対しても棚板前面上角との間に **`8.00 mm` の安全クリアランス** を常時確保し、出し入れ時の接触傷を 100% 防止する。
2. **V 字受け溝・クラウニング形状**:
   - **高さ範囲**: `v = -15.00 mm`（`Z = 0` 底面）〜 **`v = +41.40 mm`**（全高 **`56.40 mm`** `= 0.60 mm × 94`）。
   - **V 字内幅と角度**: 底面（`v = -15.00 mm`）での左右受け面内幅 **`52.00 mm`**（中央下部開口幅 `52.00 mm`）、片側基準テーパー角 **`24.0°`**（上端 `v = +41.40 mm` での内幅 **`102.22 mm`**、ホルダー最大外幅 **約 `118.0 mm`**）。
   - **太鼓 R（クラウニング）と保護フィレット**: 左右の V 字受け面に長手方向 **`R350 mm` の緩やかな凸クラウニング** を与えることで、`23.5°`（CLASH 26）と `24.2°`（EXTREME MP）の双方に対してエッジ当たりせず中央約 `40 〜 50 mm` にわたり滑らかに面接触させる。ラケットが触れる全エッジに **`R2.0 〜 R3.0 mm` のフィレット** を施し塗装傷を防ぐ。
3. **前後溝深さと手前返しリップ**:
   - **前後溝内寸**: **`26.50 mm`**（`u = +10.50 mm` 〜 手前リップ内面 `u = +37.00 mm`）。`24.0 mm` 厚（CLASH 26）および `21.0 〜 25.0 mm` 厚（EXTREME MP スロート〜肩下部）の双方がスムーズに入り、溝底前後に緩やかな R を設けてガタつきを抑える。
   - **手前返しリップ**: 肉厚 **`4.50 mm`**（前端 **`u = +41.50 mm`**、背面後端 `u = -9.20 mm` からの総奥行 **`50.70 mm`**）、左右の V 字外壁から内側へ **`11.00 mm`** 張り出すフランジとし、上端を大きく丸めて上からラケットを下ろす際のガイド性を高める。

## 6. 自動幾何検証項目（TDD / `unittest`）

1. 本番モデルおよび嵌合テストピースがそれぞれ単一閉ソリッド（`is_valid`）であり、`Z_min = 0.00 mm` に完全接地し、XY 中心が原点 `(0, 0)` に一致していること。
2. 装着姿勢において、スチール棚板（`1.15 mm` 前垂れ鉄板 ＋ 天板）との干渉体積が厳密に `0` であり、`φ7.20 mm` 丸パイプとの干渉が C スナップ先端の微小弾性干渉領域（`0.25 mm` 相当）のみに限られること。
3. SE(2) 運動学チェックにより、`0.25 mm` スナップ先端を除く本体＋J フック全高断面（高さ `56.4 mm`）が、ラック手前下方から棚板・丸パイプに一切干渉せず定位置直前まで進入・脱出できる連続経路が存在すること。
4. 両ラケット（`CLASH 26 V3.0` および `HEAD EXTREME MP 2026`）のスロート3Dモデルを上から降ろした際、スロート直線領域内で左右クレードルに安定着座し、ブリッジや棚板天面角（`u = 0, v = +18.1`）と `7.0 mm` 以上のクリアランスを保って一切干渉しないこと。
5. ビルドプレート基準でサポート材が必要となる水平宙吊り面（`> 45°` の孤立オーバーハング）が存在しないこと。
