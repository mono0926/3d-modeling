# スチールラック用 テニスラケット掛け（Steel Rack Tennis Racket Holder）設計仕様書（v2 実機適合版）

## 1. 概要と目的

マットブラックのスチールラック（天板端部が下に `18.1 mm` 折り曲げられた約 `1.0 mm` 厚スチール棚板 ＋ その垂直前面から **`2.0 mm` 手前のクリアランス** を空け、下端から **`2.0 mm` 下** に配置された `φ7.2 mm` 水平丸パイプ）に対し、カバーなしの硬式テニスラケット 2 機種（ジュニア用 **Wilson CLASH 26 V3.0** および大人用 **HEAD EXTREME MP 2026**）を **1 つのホルダーで兼用** し、ラック面に沿ってフラット（ヘッド上向き）に気持ちよく縦掛けできる専用ホルダーを設計する。

以下を同時に達成することを目的とする。

- **ネジ・テープ不要のストレートアップ装着 ＆ 完全セルフロック構造**: 左右の剛体 J フックが「約 `1.0 mm` 厚スチール棚板フチの裏面（`u = -1.25 mm`）」と「前方 `φ7.2 mm` 丸パイプの手前（`u = +10.00 mm`）」を真下から傾けずに真っ直ぐ跨ぎ、中央に完全独立配置した **`Z = 0` 連続繊維ロング板バネラッチ** が丸パイプ上肩（`+45°` 接線）へ「カチッ」と乗り上げる構造とする。ラケット自重がかかるほどロックが深く噛み込むセルフロック構造としつつ、棚板上面（`v = +18.1 mm`）への出っ張りを完全ゼロにする。
- **狭い隙間（約 `2.0 mm`）を通さず、`1.5 〜 2.5 mm` の個体差も無調整吸収**: 板の垂直面と丸パイプの間の狭い `2.0 mm` 隙間には一切パーツを通さず、前後・上下のクリアランスが `1.5 〜 2.5 mm` に変動しても無干渉で直進進入・確実ロックできること。
- **26 インチジュニア用 ＆ 27 インチ大人用の 1 モデル完全兼用**: 実測・公式仕様より両ラケットのスロート片側テーパー角が `23.5°` と `24.2°`（差わずか `0.7°`）、フレーム厚が `24.0 mm` と `21.0 〜 26.0 mm` である特性を活かし、緩やかな太鼓 R（クラウニング）付きの `24.0°` 外抱え V 字クレードルとすることで、上からスッと下ろすだけでどちらのラケットも自動調心してグラつきなく保持できること。
- **Bambu Lab P2S Combo でのサポート材・ブリッジ完全ゼロ一体造形**: 設置時の水平フラット底面（`v = -15.00 mm`）をビルドプレート（`Z = 0`）にベタ置きする 1 ピース一体造形とし、すべてのオーバーハング角を `45.0°` 以下（水平ブリッジもゼロ）に制御してサポート材 `0 g` で美しく出力できること。

## 2. 対象環境・ラケット仕様（実測値・実機テスト確認済み）

### 2.1 スチールラック嵌合部（ユーザー実測値・実機確認済み）

基準座標 `(u, v)` として、スチール棚板前面の外側垂直面を **`u = 0.00 mm`**（室内手前側を `+u`、棚奥側を `-u`）、棚板前垂れ（フチ）の下端を **`v = 0.00 mm`**（上方を `+v`、下方を `-v`）と定義する。

- **棚板前垂れ（スチール折り曲げ垂直面）**:
  - 縦高さ: **`18.1 mm`**（`v = 0.00 〜 +18.10 mm`、天板上面が `v = +18.10 mm`）
  - 板厚: **約 `1.0 mm`** の薄い鉄板（内面側に折り返しなし。公差範囲 `0.95 〜 1.20 mm` を想定し、裏側 `u < -1.20 mm, v = 0.00 〜 +17.00 mm` は高さ約 `17 mm` の中空懐空間）
- **水平丸パイプ（横桟）**:
  - 外径: **`φ7.20 mm`**（半径 `3.60 mm`）
  - 前後クリアランス: 棚板の垂直面（`u = 0.00 mm`）から丸パイプ奥面まで **約 `2.00 mm`** の空間があり、**丸パイプ全体が垂直面より手前側**に配置（パイプ奥端 `u = +2.00 mm`、中心 **`u = +5.60 mm`**、手前端 **`u = +9.20 mm`**）
  - 上下クリアランス: 棚板下端（`v = 0.00 mm`）から丸パイプ上端まで **約 `2.00 mm`** の空間（パイプ上端 `v = -2.00 mm`、中心 **`v = -5.60 mm`**、下端 `v = -9.20 mm`）

### 2.2 対象テニスラケット（2 機種兼用）

1. **HEAD EXTREME MP 2026（品番: `233316` / 大人用 27.0 インチ G2）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `300 g`（ガット張り上げ時 約 `315 〜 320 g`）
   - フレーム前後厚（公式仕様）: **`23 / 26 / 21 mm`**（先端 `23 mm` / フェイス肩部最大 `26 mm` / スロート・シャフト部 `21 mm`）
   - スロート実測寸法（ユーザー計測値）:
     - 三角穴の下角高さでの左右外幅: **約 `41 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `130 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((130 - 41) / (2 \times 99)) \approx \mathbf{24.2^\circ}$
2. **Wilson CLASH 26 V3.0（ジュニア用 26.0 インチ）**:
   - フェイス面積 / 重量: `100 sq.in.` / 平均 `245 g`（ガット張り上げ時 約 `260 g`）
   - フレーム前後厚（公式仕様）: **`24.0 - 24.0 - 24.0 mm`**（フラットビーム `24.0 mm`）
   - スロート寸法（全長 `660.4 mm` 基準の正面商品画像ピクセル校正値）:
     - 三角穴の下角高さでの左右外幅: **約 `35 mm`**
     - 三角穴の上端（横棒下）高さでの左右外幅: **約 `121 mm`**
     - 三角穴の縦内寸高さ: **約 `99 mm`**
     - 算出片側テーパー角: $\arctan((121 - 35) / (2 \times 99)) \approx \mathbf{23.5^\circ}$

## 3. アプローチの比較と選定経緯

1. **案 1（採用）：外抱え V 字クレードル型（ヘッド上向き）**
   - スロート外側の V 字テーパーを左右の斜めガイドと手前の返しリップで抱え込む方式。上から下ろすだけで自然にセンターへ収まり、左右 2 辺を面で受けるため揺れにくく、未収納時もツノ状の突起が出ず安全性が高い。
2. **案 2（不採用）：センター 1 本フック型（三角穴掛け・ヘッド下向き）**
   - 逆さま掛けの見栄えになるうえ、丸パイプから下へ約 `55 〜 60 cm` 垂れ下がり下段の収納物と干渉しやすい。
3. **案 3（不採用）：二股ダブルピン型（ヘッド上向き）**
   - 未収納時に 2 本のピンが手前へ突き出し、点支持に近いため案 1 より前後に傾きやすい。

## 4. 詳細構造設計（v2 実機適合設計）

### 4.1 素材・造形ピッチ最適化

- **推奨フィラメント**: **マットブラック系の `PETG` または `PLA Tough / PLA Matte`**（板バネ着脱時の靭性と長期耐クリープ性の観点から **`PETG`（Bambu PETG HF / Matte 等）を第一推奨**、連続繊維ひずみ `1.18%`・層間引張応力 `12.7 MPa` 以下の安全設計のため PLA 系でも割れずに使用可能）。
- **レイヤー高さ両対応設計**: 全高 `56.40 mm`（`0.60 × 94`）、テストピース高 `28.80 mm`（`0.60 × 48`）、底面板バネ厚 `1.80 mm`（`0.60 × 3`）と主要高さをすべて **`0.60 mm` の整数倍** で設計し、`0.20 mm` レイヤーと `0.30 mm` レイヤーの両方に端数なく対応する。

### 4.2 ラック固定機構：「ストレートアップ剛体デュアル J フック ＋ `Z = 0` 独立ロング板バネラッチ」

1. **真下から傾けずに直進進入する左右の剛体デュアル J フック**:
   - 左右 `x = -28.00 〜 -8.50 mm` および `+8.50 〜 +28.00 mm`（各幅 `19.50 mm`、計 `39.00 mm` 幅）に高剛性なコの字 J フックを配置。
   - 後側ストッパー面 **`u = -1.25 mm`**（下部入口は `45°` 導入面取りで `-2.05 mm` まで拡幅）が約 `1.0 mm` 薄鉄板の裏面（`u ≈ -1.05 mm`）へ入り、前側ガイド内壁 **`u = +10.00 mm`** が丸パイプ手前端（`u = +9.20 mm`）の外側を通る。
   - 開口幅 `11.25 mm`（入口 `12.85 mm`）により、薄鉄板＋前後クリアランス＋丸パイプの合計幅（標準 `10.25 mm`、最大想定 `11.00 mm`）を **傾き `0°` のまま真下からスッと跨ぐ** ことができる。
2. **完全分離された `Z = 0` 連続繊維ロング板バネラッチ（Castigliano ばね設計）**:
   - 中央ベイ（`x = -8.50 〜 +8.50 mm`）内に、左右 **`2.00 mm` の貫通分離スリット** と背面 **`5.00 mm` のたわみ逃げポケット** で周囲から完全に切り離した幅 **`13.00 mm`** の L 字ロング板バネを配置。
   - 背面下部クロスバー（`u = -5.20 〜 -1.80 mm`）を固定端とし、ビルドプレート `Z = 0` 上を水平に `u = +11.70 mm` まで伸びる **板厚 `1.80 mm` × 有効スパン `13.50 mm` の連続繊維リーフ** が主たわみを担うため、垂直ステム（肉厚 `3.00 mm`）の層間 Z 引張応力は **PETG `8.9 MPa` / PLA `12.7 MPa`** と極めて低く、層間剥離リスクがない。
   - 押し込みクリック力は標準 `2.30 mm` たわみ時で **PETG 約 `1.4 kgf`（`14.1 N`）/ PLA 約 `2.0 kgf`（`20.2 N`）** と指先で心地よく「カチッ」と嵌まる強さに最適化されている。
   - ラッチ下面（`u + v = 4.85`、先端 `u = +6.70, v = -1.85`、造形オーバーハング厳密 `45.0°`）が丸パイプ上肩（`+45°`）へ乗り上げ、ラケット荷重のお辞儀モーメントによって薄鉄板裏ストッパーと丸パイプの間でさらに深く噛み込むセルフロックが成立する。取り外す際は上部のリリースタブ（`v = +6.00 mm`）を指先で手前ポケット側へ軽く押すだけで解除できる。

### 4.3 2 機種兼用・外抱え V 字クレードル設計

- **クレードル位置と棚板クリアランス**: 逃げポケット後方の剛体フロントスパイン兼クレードル背板を `u = +18.20 〜 +21.80 mm` に配置し、ラケット受け溝を **`u = +21.80 〜 +48.30 mm`（溝深さ `26.50 mm`）**、手前返しリップ外端を `u = +52.80 mm` とする。これにより最大厚 `26.0 mm` 肩部でも棚板前面（`u = 0.00 mm`）から **`22.0 mm` 以上**、丸パイプ手前端（`u = +9.20 mm`）からも **`12.8 mm` 以上** 離れ、出し入れ時の接触傷を 100% 防止する。
- **V 字受け溝・クラウニング・保護 R**: 底面内幅 `52.00 mm`、片側基準テーパー角 `24.0°`、中央 `0.45 mm` 凸の太鼓クラウニング曲面（`R350 mm` 相当）、外周 `R3.0 mm` / ラケット接触部 `R1.8 mm` フィレット / 上端 `C1.2 mm` 導入面取りを備える。

## 6. 自動幾何・公差・力学検証項目（TDD / `unittest` 全 7 項目）

1. 丸パイプ前方配置（`PIPE_CENTER_U = +5.60 mm`）定数、単一閉ソリッド（`is_valid`）、`Z = 0` 完全接地、XY 原点中心、`0.60 mm` 整数倍高さの検証。
2. 前後・上下クリアランス `1.5 〜 2.5 mm`・板厚 `0.95 〜 1.20 mm` の 5 条件すべてで剛体 J フックが棚板・パイプと干渉体積 `0` で着座し、ラッチ噛み込み量 `>= 1.60 mm`・底面オーバーストローク余裕 `>= 1.00 mm`・天面出っ張りゼロを満たすこと。
3. 除外点なしの全 3D ブーリアン検証により、剛体フレームが真下（`dv = -24 mm`）から傾き `0°` のまま無干渉で直進進入できること。
4. 中央板バネの左右分離スリット・背面 `5.0 mm` ポケット・リーフ上空間が完全貫通空間であり、Castigliano エネルギー法による押し込み力が適正範囲（PETG `10〜19 N` / PLA `14〜26 N`）かつ層間応力 `< 14 MPa` であること。
5. `CLASH 26 V3.0` と `HEAD EXTREME MP 2026` の双方が V 字溝に安定着座し、棚板・丸パイプから十分なクリアランスを保つこと。
6. `Z > 0.15 mm` に `> 46.9°` の急オーバーハングや水平ブリッジが存在せず、STEP 入出力が正常に往復できること。
7. ラケット接触部の保護フィレットおよびテストピース前後の高さ差（手前 V ノッチ側 `28.80 mm` / 棚裏ストッパー側 `23.40 mm`）による前後識別性の検証。
