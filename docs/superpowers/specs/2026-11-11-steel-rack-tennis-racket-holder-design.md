# スチールラック用 テニスラケット掛け（Steel Rack Tennis Racket Holder）設計仕様書（v5 独立3連クレードル＆高保持ロック版）

## 1. 概要と目的

マットブラックのスチールラック（天板端部が下に `18.1 mm` 折り曲げられた約 `1.0 mm` 厚スチール棚板 ＋ その垂直前面から **`2.0 mm` 手前のクリアランス** を空け、下端から **`2.0 mm` 下** に配置された `φ7.2 mm` 水平丸パイプ）に対し、カバーなしの硬式テニスラケット 2 機種（ジュニア用 **Wilson CLASH 26 V3.0** および大人用 **HEAD EXTREME MP 2026**）を **最大 3 本まで独立して前後に重ね掛け** できる専用 3 連ホルダーを設計する。

以下を同時に達成することを目的とする。

- **独立 3 連 V 字クレードル（`32.00 mm` ピッチ / 最大 3 本収納）**: `26.50 mm` 溝 ＋ `5.50 mm` 保護 R 付き仕切りリブ × 3 連とすることで、フレーム同士の接触傷ゼロ、1 本掛け時の前後倒れゼロ、グリップエンド（約 `34 mm` 厚）同士の干渉ゼロを実現する。さらに全仕切りの中央に前後スルー通路（底幅 `30 mm` → 上幅 `80 mm`）を貫通させ、天井が近い最上段でもわずかな持ち上げ量で出し入れできる。
- **3 本分（約 `900 g`）の片持ち荷重にたわまないストレート直結サイドフレーム**: 左右の剛体 J フック外幅をクレードル外壁と同一の **`67.60 mm`（片側 `33.80 mm`）** に揃えて一直線に直結し、背板スパイン肉厚も **`4.80 mm`** へ強化する。
- **実機検証済み v4 高保持ロック機構の 100% 継承**: 段付き丸パイプ専用ポケット（幅 `7.70 mm`）＋ 頂点越え常時予圧ディープフック（`u = +4.55 mm`、直立耐力 `7.3 〜 10.4 kgf`、斜め `25°` 抜け抵抗 `5.3 〜 7.5 kgf`）＋ 指掛けリリースタブ（`v = +9.60 mm`）をそのまま維持する。
- **Bambu Lab P2S Combo でのサポート材・ブリッジ完全ゼロ一体造形**: 外寸 `117.01 × 128.50 × 56.40 mm` で `256 mm` プレートに余裕で収まり、`Z = 0` ベタ置き・全オーバーハング `55.0°` 以下・`0.60 mm` 整数倍高さで美しく一体出力できること。

## 2. 対象環境・ラケット仕様（実測値・v2〜v4 実機テスト確認済み）

### 2.1 スチールラック嵌合部

基準座標 `(u, v)` として、スチール棚板前面の外側垂直面を **`u = 0.00 mm`**（手前 `+u`、奥 `-u`）、棚板前垂れ下端を **`v = 0.00 mm`**（上方 `+v`、下方 `-v`）と定義する。

- **棚板前垂れ**: 縦高さ **`18.1 mm`**（`v = 0.00 〜 +18.10 mm`）、板厚 **約 `1.00 mm`**。
- **水平丸パイプ**: 外径 **`φ7.20 mm`**、板前面から丸パイプ奥面まで **約 `1.95 〜 2.00 mm`**、板下端から丸パイプ上端まで **約 `2.00 mm`**（公称中心 `(u = +5.60 mm, v = -5.60 mm)`）。

### 2.2 対象テニスラケット（全 3 スロット 2 機種完全兼用）

1. **HEAD EXTREME MP 2026（`233316` / 大人用 27.0 インチ G2）**: `100 sq.in.` / `300 g`、ビーム厚 `23 / 26 / 21 mm`、片側テーパー角 **約 `24.2°`**。
2. **Wilson CLASH 26 V3.0（ジュニア用 26.0 インチ）**: `100 sq.in.` / `245 g`、フラットビーム厚 `24.0 mm`、片側テーパー角 **約 `23.5°`**。

## 3. 詳細構造設計（v5 独立 3 連スロット ＋ v4 高保持ロック）

1. **ラック固定コア（v4 継承 ＋ 幅 `67.60 mm` 強化）**:
   - 左右剛体 J フック：`x = ±9.80 〜 ±33.80 mm`（各幅 `24.00 mm`、計 `48.00 mm`）、上部スカート壁 `u = -1.06 mm`（高さ `+12.60 mm`）、下部パイプ専用座 `u = +1.62 〜 +9.32 mm`（幅 `7.70 mm`、底面 `v = -9.55 mm`）。
   - 中央 `Z = 0` ロング板バネラッチ：幅 `16.00 mm`、リーフ厚 `1.80 mm` × スパン `15.05 mm`、ステム厚 `3.60 mm`、爪先 `(u = +4.55 mm, v = -1.42 mm)`、リリースタブ上端 `v = +9.60 mm`。
2. **独立 3 連 V 字クレードル（`NUM_RACKET_SLOTS = 3`）**:
   - 背板スパイン：`u = +21.90 〜 +26.70 mm`（肉厚 `4.80 mm`）。
   - 第 1 スロット（奥）：`u = +26.70 〜 +53.20 mm`（中心 `+39.95 mm`）
   - 第 1 仕切りリブ：`u = +53.20 〜 +58.70 mm`（肉厚 `5.50 mm`）
   - 第 2 スロット（中央）：`u = +58.70 〜 +85.20 mm`（中心 `+71.95 mm`）
   - 第 2 仕切りリブ：`u = +85.20 〜 +90.70 mm`（肉厚 `5.50 mm`）
   - 第 3 スロット（手前）：`u = +90.70 〜 +117.20 mm`（中心 `+103.95 mm`）
   - 最前列返しリップ：`u = +117.20 〜 +121.70 mm`（肉厚 `4.50 mm`、全体奥行 **`128.50 mm`**）
   - 全スロットとも底面内幅 `52.00 mm`、片側基準角 `24.0°`、`0.45 mm` 太鼓クラウニング、外周 `R3.0 mm` / ラケット接触部 `R1.5 mm` フィレット / 上面全周 `C1.0 mm` 面取りを備える。
