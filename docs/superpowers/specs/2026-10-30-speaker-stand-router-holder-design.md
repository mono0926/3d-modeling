# スピーカースタンド背面 ルーター吊り下げホルダー（Speaker Stand Router Holder）設計仕様書

## 1. 概要と目的

木製スピーカースタンド（BQKOZFIN 高さ 80cm）の背面中央に引っ掛けて、Wi-Fi 6E ルーター（NEC Aterm WX7800T8、約 800g）を付属スタンド装着のまま正規の縦置き姿勢でスマート・強固に吊り下げ配置する専用ホルダーを設計する。

仮固定のガムテープを廃し、以下を同時に満たすことを目的とする。

- 天板上の HomePod および、左側面から出る LAN ケーブル・電源ケーブルと一切干渉しないこと。
- メーカー推奨の「正規の縦置き」を維持し、支柱側・底面側・背面側の通気と電波透過性を確保すること。
- Bambu Lab P2S Combo（`256 × 256 × 256 mm`）にて **分割なしの 1 パーツ一体造形・サポート材完全ゼロ（0g）** で失敗リスクなく造形できること。

## 2. 対象機器・設置環境の実寸条件

### 2.1 スピーカースタンド（BQKOZFIN 木製・高さ 80cm）

- **天板厚み**: `15.5 mm`（ノギス実測、嵌合テストピースにて溝幅 `15.8 mm` の良好なフィットを実機確認済み）
- **天板横幅 × 奥行**: 横幅 `183.0 mm`（実測、カタログ値 `190.0 mm`）× 奥行 `235.0 mm`
- **木製支柱（横幅 × 奥行）**: `113.8 mm × 116.6 mm`（ノギス実測）
- **天板裏の背面張り出し量（支柱背面 〜 天板後端）**: **`61.0 mm`**（嵌合テストピース実機当て確認を経て再実測した確定値）
- **天板上の空き距離（HomePod 背面 〜 天板後端）**: 約 `75.0 mm`
- **壁面クリアランス（天板後端 〜 後ろの壁）**: 約 `32.0 〜 34.0 mm`（支柱背面 〜 後ろの壁は約 `93.0 〜 95.0 mm`）

### 2.2 ルーター（NEC Aterm WX7800T8・付属スタンド装着時）

- **設置姿勢**: 正規の縦置き（付属の白い楕円スタンドが底面）
  - **手前（支柱側）**: 通気スリット（穴）のある広い面
  - **奥（壁側）**: フラットな Aterm ロゴ面
  - **右側（正面から見て右）**: ステータス LED ランプ面（右側からスライドして出し入れ）
  - **左側（正面から見て左）**: WAN/LAN ポート × 5・AC 電源コネクタ面（左側へ配線）
- **スタンド込み全高**: 約 `197.0 mm`（カタログ値 `196.5 mm`）
- **ルーター本体横幅（長辺）**: 約 `213.5 mm`
- **ルーター本体厚み（短辺）**: 約 `55.0 mm`
- **付属スタンド短辺幅 × 長辺長さ**: 幅 `75.0 mm`（定規実測、NEC 公式公称値 約 `76.0 mm`）× 長さ 約 `184.0 mm`（本体厚み `55.0 mm` より前後に約 `10.0 mm` ずつ張り出す）

## 3. 素材および製造環境

- **使用フィラメント**: Bambu PETG Basic（黒）
  - 黒天板およびルーター筐体と自然に一体化する外観。
  - カーボン繊維（CF）を含まない純粋な PETG 樹脂のため、2.4GHz / 5GHz / 6GHz（Wi-Fi 6E）の電波減衰がゼロであり、常時発熱（40〜50℃前後）と 800g 静荷重に対する耐熱性・耐クリープ性・粘り強さを兼ね備える。
- **使用プリンター / ノズル**: Bambu Lab P2S Combo / `0.6 mm` タングステンカーバイドノズル
- **基準レイヤー高さ**: `0.30 mm`（`0.6 mm` ノズルの標準積層ピッチ、積層方向の総高さを `0.30 mm` の整数倍で設計）
- **サポート材**: なし（完全サポートフリー）

## 4. 構造設計と各部寸法（v2 段付き C 字フック仕様）

### 4.1 造形向きと座標系定義（Bambu Studio インポート時基準）

スライサーへインポートした状態でそのままサポート無し造形できるよう、**「設置時の右側面（LED 側）」をビルドプレート接地面（`Z = 0`）として寝かせた姿勢**をモデルの標準座標系とする（XY 平面の中心を原点 `(0, 0)` 付近に配置）。

- **`Z` 軸（積層方向 ＝ 設置時の右 → 左方向）**:
  - ホルダー全幅 `HOLDER_WIDTH = 144.00 mm`（`0.30 mm × 480 層`）
  - 天板横幅が実測 `183.0 mm`・カタログ `190.0 mm` のいずれであっても、天板左右の角丸を避けて背面中央に美しく収まり、支柱幅（`113.8 mm`）全体をしっかりカバーする。
- **`X` / `Y` 軸（ビルドプレート平面 ＝ 設置時の側面断面プロファイル）**:
  - 断面外寸: **`236.6 mm × 89.5 mm`**（`256 × 256 mm` ビルドプレート内に十分な余白をもって 1 パーツで収まる）。
  - 段付き天板フックから斜めガセット・背面スパイン・底面 U 字トレイまで、`0.6 mm` ノズルの外周ループが一筆書きで連続する積層方向となるため、層間剥離によるフック破断リスクを構造的に排除する。

### 4.2 側面断面プロファイル詳細（段付き C 字フック ＋ スリム下部構造）

天板の背面張り出し量（`61.0 mm`）よりもルーター付属スタンド幅（実測 `75.0 mm` / 公称 約 `76.0 mm` → トレイ外寸 `82.0 mm`）の方が大きいため、**上部は天板後端（`61.5 mm` 位置）にピタッと突き当たる段付き C 字フック、下部はスタンドを無理なく収めつつ壁との余裕を確保するスリム奥行（`83.5 mm` 位置）** の 2 段オフセット構造とする。

1. **天板背面 段付き C 字フック部**:
   - **天板後端突き当てリーチ**: `HOOK_OVERHANG_REACH = 61.5 mm`（支柱背面からの天板張り出し実測 `61.0 mm` ＋ クリアランス `0.5 mm`）。支柱当てパッドが支柱背面に当たると同時に C 字フック奥壁が天板後端付近へ収まり、溝奥の無駄な隙間を解消する。
   - **上ツメ奥行（天板上面へのかかり代）**: `TOP_LIP_DEPTH = 52.0 mm`（C 字フック奥壁から前方へ `52.0 mm` 延ばし、実際の天板上面に **`51.5 mm`** しっかり載せることで高い安定性を確保。HomePod 背面との間にも約 `23.5 mm` の安全マージンを残し、ルーター重心の真上を完全にカバーする）。
   - **上ツメ肉厚**: `TOP_LIP_THICKNESS = 4.8 mm`（先端上角にフィレットを施し、天板上で目立たない薄型エッジとする）。
   - **天板噛み合い溝幅**: `TOP_PLATE_SLOT_GAP = 15.8 mm`（実測 `15.5 mm` ＋ クリアランス `0.3 mm`、テストピースで検証済み）。
   - **フック背面リムと斜めガセット接続**: 天板高さ付近では天板後端から `HOOK_BACK_WALL_THICKNESS = 6.0 mm` のスマートな縁取りのみとし、天板中腹から天板裏アーム下面にかけて斜めガセット（三角リブ）で下部の背面スパイン外壁（`89.5 mm` 位置）へ滑らかに接続することで、上部からの見た目のスッキリ感と首元の高い曲げ剛性を両立する。
2. **天板裏アーム ＆ 支柱当てパッド部**:
   - **天板裏アーム肉厚**: `UNDER_ARM_THICKNESS = 6.0 mm`
   - **下部背面スパインリーチ（支柱当て前端 〜 背面スパイン内壁）**: `SPINE_INNER_REACH = 83.5 mm`（底面トレイ内寸 `77.0 mm` ＋ 前ストッパー厚 `5.0 mm` ＋ 支柱背面との逃げ `1.5 mm`）。
   - **支柱当てパッド**: 天板裏アーム先端から下方へ `PILLAR_PAD_DROP = 32.0 mm`（総高さ `38.0 mm`、厚み `5.5 mm`）垂下させ、フラットな木製支柱背面に面接触して前傾・グラつきを抑える。
3. **背面縦スパイン部**:
   - **肉厚**: `WALL_THICKNESS = 6.0 mm`
   - **全体外寸奥行**: `TOTAL_DEPTH = 83.5 + 6.0 = 89.5 mm`。天板後端（`61.0 mm`）から壁側への突出は `28.5 mm` に収まり、後ろの壁（隙間 約 `32.0 〜 34.0 mm`）との間に余裕を確保する。
   - **ルーター収容有効高さ**: `ROUTER_CHAMBER_HEIGHT = 204.0 mm`（ルーター全高 約 `197.0 mm` ＋ 上部クリアランス `7.0 mm` により、横スライドでの出し入れを容易にする）。
   - **ホルダー総高さ（断面長辺）**: `4.8 + 15.8 + 6.0 + 204.0 + 6.0 = 236.6 mm`
4. **底面 U 字トレイ部（左右貫通スライドレール）**:
   - **底板肉厚**: `WALL_THICKNESS = 6.0 mm`
   - **トレイ内寸奥行**: `STAND_TRAY_INNER_DEPTH = 77.0 mm`（付属スタンド実測幅 `75.0 mm` に片側 `1.0 mm`、NEC 公称最大幅 約 `76.0 mm` にも片側 `0.5 mm` のわずかなクリアランス、底角はゴム足が乗り上げない `R1.0 mm` フィレット）。これによりルーター本体（厚み約 `55.0 mm`）の通気穴面と木製支柱背面の間に約 `17 mm` の通気空間が確保される。
   - **前ストッパーリップ（支柱側）**: 内側立ち上がり高さ `FRONT_LIP_INNER_HEIGHT = 14.0 mm`（外寸高さ `20.0 mm`）、肉厚 `FRONT_LIP_THICKNESS = 5.0 mm`。前端位置は支柱背面から `1.5 mm` 離れた位置となり、着脱時や使用時に支柱と干渉しない。
   - **左右端の仕様（左右貫通オープン）**: 付属スタンド長辺（約 `184.0 mm`）がホルダー全幅（`144.0 mm`）より長いため、底面 U 字トレイは左右に壁を設けない貫通構造とし、左右位置の微調整と左側 LAN・電源ケーブルの完全非干渉を両立する。

### 4.3 印刷失敗リスクゼロの大開口（五角形ティアドロップアーチ窓）

造形時の失敗リスク（1 層目の剥がれ、細い斜め格子の反り上がり・ノズル衝突、水平ブリッジ垂れ）を一切増やさず、通気性向上とフィラメント削減・熱収縮反り軽減を両立するため、以下のルールで開口を設ける。

1. **上下の連続ソリッド枠の維持**:
   - ビルドプレート接地面側 **`Z = 0.0 〜 18.0 mm`（60 層）** は開口無しの完全連続ループとし、1 層目の密着面積を 100% 維持するとともに、外から見える右側端面をフラットで美しい外観に仕上げる。
   - 造形上端側 **`Z = 126.0 〜 144.0 mm`（60 層）** も完全連続ループに合流させ、箱型フレームとしてのねじれ剛性を維持する。
2. **開口形状（垂直太柱 ＋ 屋根角 40° 五角形アーチ）**:
   - `Z = 18.0 mm` をフラットな底辺とし、`Z` 方向へ真っ直ぐ垂直（オーバーハング `0°`）に立ち上げた後、上端を**垂直から `40°`（水平から `50°`）の急勾配山形屋根**で閉じ、全頂点に `R4.0 mm` フィレット（頂点はティアドロップ丸め）を付与する。
3. **開口の配置箇所**:
   - **背面縦スパイン（有効長 `204.0 mm`）**: 幅 `48.0 mm` の五角形アーチ大開口を **3 窓** 配置する。窓間の柱幅は `16.0 mm`（上下端マージン各 `14.0 mm`）とし、造形時はベッドから垂直 `90°` に立ち上がる太柱となるため揺れや反り上がりが発生しない。
   - **底面トレイ床面（内寸奥行 `77.0 mm`）**: 中央に幅 `44.0 mm` の同形状五角形アーチ開口を **1 窓** 配置する（前後各 `16.50 mm` のスタンド受けレールを維持）。
   - **天板裏フロントアーム（支柱パッド内面 〜 C フック奥壁の有効スパン `56.0 mm`）**: 中央に幅 `30.0 mm` の同形状五角形アーチ開口を **1 窓** 配置する（前後各 `13.0 mm` のソリッド枠を残し、C フック奥壁〜背面スパイン間の荷重伝達ショルダー部は 100% 無開口ソリッドとして最高強度を維持する）。
   - **天板上面ツメ（`52.0 mm`）**: 荷重支持部かつ外観面のため、開口無しのソリッド形状とする。

### 4.4 応力集中対策とエッジ処理

- C 字フック内角・段付きガセット遷移部・トレイ内角などの応力集中部には `R0.8 〜 R6.0 mm` のフィレットを付与し、機器や天板との非干渉と割れ防止を両立する。
- 天板差し込み口には導入フィレット（リードイン）を施し、塗装家具への傷付きを防ぐ。

## 6. パラメトリック設計と検証項目

- すべての主要寸法・クリアランス・肉厚・窓角度をスクリプト冒頭の大文字定数として定義する。
- 生成後の STEP / ソリッドに対して以下の自動幾何検証を行う。
  1. 単一閉ソリッド（Watertight / Valid Solid、体積 > 0）であること。
  2. バウンディングボックスが `Z_min = 0.0 mm` に接地し、外寸 `236.6 × 89.5 × 144.0 mm` で P2S 造形領域（`256 × 256 × 256 mm`）内に余裕をもって収まること。
  3. 天板溝幅（`15.8 mm`）、天板張り出し突き当てリーチ（`61.5 mm`）、実効天板かかり代（`51.5 mm`）、下部スパインリーチ（`83.5 mm`）、スタンド受け内寸（`77.0 mm`）、ルーター有効高さ（`204.0 mm`）が設計値通りであり、実寸 `15.5 mm × 張り出し 61.0 mm` の天板および木製支柱と一切干渉しないこと。
