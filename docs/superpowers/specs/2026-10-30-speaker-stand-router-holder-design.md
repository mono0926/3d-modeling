# スピーカースタンド背面 ルーター吊り下げホルダー（Speaker Stand Router Holder）設計仕様書

## 1. 概要と目的

木製スピーカースタンド（BQKOZFIN 高さ 80cm）の背面中央に引っ掛けて、Wi-Fi 6E ルーター（NEC Aterm WX7800T8、約 800g）を付属スタンド装着のまま正規の縦置き姿勢でスマート・強固に吊り下げ配置する専用ホルダーを設計する。

仮固定のガムテープを廃し、以下を同時に満たすことを目的とする。

- 天板上の HomePod および、左側面から出る LAN ケーブル・電源ケーブルと一切干渉しないこと。
- メーカー推奨の「正規の縦置き」を維持し、支柱側・底面側・背面側の通気と電波透過性を確保すること。
- Bambu Lab P2S Combo（`256 × 256 × 256 mm`）にて **分割なしの 1 パーツ一体造形・サポート材完全ゼロ（0g）** で失敗リスクなく造形できること。

## 2. 対象機器・設置環境の実寸条件

### 2.1 スピーカースタンド（BQKOZFIN 木製・高さ 80cm）

- **天板厚み**: `15.5 mm`（ノギス実測）
- **天板横幅 × 奥行**: 横幅 `183.0 mm`（実測、カタログ値 `190.0 mm`）× 奥行 `235.0 mm`
- **木製支柱（横幅 × 奥行）**: `113.8 mm × 116.6 mm`（ノギス実測）
- **天板裏の背面張り出し量（支柱背面 〜 天板後端）**: 約 `90.0 mm`
- **天板上の空き距離（HomePod 背面 〜 天板後端）**: 約 `75.0 mm`
- **壁面クリアランス（天板後端 〜 後ろの壁）**: 約 `32.0 mm`（支柱背面 〜 後ろの壁は約 `122.0 mm`）

### 2.2 ルーター（NEC Aterm WX7800T8・付属スタンド装着時）

- **設置姿勢**: 正規の縦置き（付属の白い楕円スタンドが底面）
  - **手前（支柱側）**: 通気スリット（穴）のある広い面
  - **奥（壁側）**: フラットな Aterm ロゴ面
  - **右側（正面から見て右）**: ステータス LED ランプ面（右側からスライドして出し入れ）
  - **左側（正面から見て左）**: WAN/LAN ポート × 5・AC 電源コネクタ面（左側へ配線）
- **スタンド込み全高**: 約 `197.0 mm`（カタログ値 `196.5 mm`）
- **ルーター本体横幅（長辺）**: 約 `213.5 mm`
- **ルーター本体厚み（短辺）**: 約 `55.0 mm`
- **付属スタンド短辺幅 × 長辺長さ**: 幅 `75.0 mm` × 長さ 約 `184.0 mm`（本体厚み `55.0 mm` より前後に約 `10.0 mm` ずつ張り出す）

## 3. 素材および製造環境

- **使用フィラメント**: Bambu PETG Basic（黒）
  - 黒天板およびルーター筐体と自然に一体化する外観。
  - カーボン繊維（CF）を含まない純粋な PETG 樹脂のため、2.4GHz / 5GHz / 6GHz（Wi-Fi 6E）の電波減衰がゼロであり、常時発熱（40〜50℃前後）と 800g 静荷重に対する耐熱性・耐クリープ性・粘り強さを兼ね備える。
- **使用プリンター / ノズル**: Bambu Lab P2S Combo / `0.6 mm` ノズル
- **基準レイヤー高さ**: `0.30 mm`（`0.6 mm` ノズルの標準積層ピッチ、積層方向の総高さを `0.30 mm` の整数倍で設計）
- **サポート材**: なし（完全サポートフリー）

## 4. 構造設計と各部寸法

### 4.1 造形向きと座標系定義（Bambu Studio インポート時基準）

スライサーへインポートした状態でそのままサポート無し造形できるよう、**「設置時の右側面（LED 側）」をビルドプレート接地面（`Z = 0`）として寝かせた姿勢**をモデルの標準座標系とする（XY 平面の中心を原点 `(0, 0)` 付近に配置）。

- **`Z` 軸（積層方向 ＝ 設置時の右 → 左方向）**:
  - ホルダー全幅 `HOLDER_WIDTH = 144.00 mm`（`0.30 mm × 480 層`）
  - 天板横幅が実測 `183.0 mm`・カタログ `190.0 mm` のいずれであっても、天板左右の角丸を避けて背面中央に美しく収まり、支柱幅（`113.8 mm`）全体をしっかりカバーする。
- **`X` / `Y` 軸（ビルドプレート平面 ＝ 設置時の側面断面プロファイル）**:
  - 断面外寸: **`236.6 mm × 95.0 mm`**（`256 × 256 mm` ビルドプレート内に十分な余白をもって 1 パーツで収まる）。
  - 天板フックから背面スパイン・底面 U 字トレイまで、`0.6 mm` ノズルの外周ループが一筆書きで連続する積層方向となるため、層間剥離によるフック破断リスクを構造的に排除する。

### 4.2 側面断面プロファイル詳細

1. **天板背面 C 字フック部**:
   - **上ツメ奥行（天板上面へのかかり代）**: `TOP_LIP_DEPTH = 45.0 mm`（HomePod 背面まで約 `30.0 mm` の安全マージンを残しつつ、ルーター重心の真上まで天板上面で荷重を受けることで傾きモーメントを抑える）。
   - **上ツメ肉厚**: `TOP_LIP_THICKNESS = 4.8 mm`（先端上角に大きめの面取り・フィレットを施し、天板上で目立たない薄型エッジとする）。
   - **天板噛み合い溝幅**: `TOP_PLATE_SLOT_GAP = 15.8 mm`（実測 `15.5 mm` ＋ クリアランス `0.3 mm`）。開口部上下に導入面取り（リードイン）を設け、塗装天板を傷つけずスムーズに差し込める形状とする。
2. **天板裏アーム ＆ 支柱当てパッド部**:
   - **天板裏アーム肉厚**: `UNDER_ARM_THICKNESS = 6.0 mm`
   - **天板裏張り出しリーチ**: `OVERHANG_ARM_DEPTH = 89.0 mm`（定規実測 約 `90.0 mm` に対し `-1.0 mm` の安全マージンを持たせ、天板後端まで確実に奥まで差し込める長さとする）。
   - **支柱当てパッド**: 天板裏アーム先端から下方へ `PILLAR_PAD_DROP = 32.0 mm`（総高さ `38.0 mm`、厚み `5.5 mm`）垂下させ、木製支柱背面に面接触して前傾・グラつきを抑える。
3. **背面縦スパイン部**:
   - **肉厚**: `WALL_THICKNESS = 6.0 mm`
   - 天板後端から壁側への突出は `6.0 mm` のみとし、後ろの壁（隙間 約 `32.0 mm`）との間に約 `26.0 mm` の余裕を確保する。
   - **ルーター収容有効高さ**: `ROUTER_CHAMBER_HEIGHT = 204.0 mm`（ルーター全高 約 `197.0 mm` ＋ 上部クリアランス `7.0 mm` により、横スライドでの出し入れを容易にする）。
   - **ホルダー総高さ（断面長辺）**: `4.8 + 15.8 + 6.0 + 204.0 + 6.0 = 236.6 mm`
4. **底面 U 字トレイ部（左右貫通スライドレール）**:
   - **底板肉厚**: `WALL_THICKNESS = 6.0 mm`
   - **トレイ内寸奥行**: `STAND_TRAY_INNER_DEPTH = 76.5 mm`（付属スタンド幅 `75.0 mm` ＋ クリアランス `1.5 mm`）。これによりルーター本体（厚み約 `55.0 mm`）の通気穴面と木製支柱背面の間に約 `22〜24 mm` の通気空間が自然に確保される。
   - **前ストッパーリップ（支柱側）**: 内側立ち上がり高さ `FRONT_LIP_INNER_HEIGHT = 14.0 mm`（外寸高さ `20.0 mm`）、肉厚 `FRONT_LIP_THICKNESS = 5.0 mm`。付属スタンドの前ズレ・落下を確実に防ぎつつ、ルーター下部の吸気アーチを塞がない高さとする。また前端位置は `76.5 + 5.0 = 81.5 mm` となり、支柱背面（`89.0〜90.0 mm`）と干渉しない。
   - **左右端の仕様（左右貫通オープン）**: 付属スタンド長辺（約 `184.0 mm`）がホルダー全幅（`144.0 mm`）より長いため、底面 U 字トレイは左右に壁を設けない貫通構造とする。これにより、右端を天板端とツライチに揃える配置から中央配置まで左右位置を自在に微調整でき、左側面の LAN・電源ケーブルとも 100% 非干渉となる（水平トレイ＋本体 800g ＋付属スタンド底面ゴム足の摩擦により自然滑走は生じない）。

### 4.3 印刷失敗リスクゼロの大開口（五角形ティアドロップアーチ窓）

造形時の失敗リスク（1 層目の剥がれ、細い斜め格子の反り上がり・ノズル衝突、水平ブリッジ垂れ）を一切増やさず、通気性向上とフィラメント約 30〜35% 削減・長手方向の熱収縮反り軽減を両立するため、以下のルールで開口を設ける。

1. **上下の連続ソリッド枠の維持**:
   - ビルドプレート接地面側 **`Z = 0.0 〜 18.0 mm`（60 層）** は開口無しの完全連続ループとし、1 層目の密着面積を 100% 維持するとともに、外から見える右側端面をフラットで美しい外観に仕上げる。
   - 造形上端側 **`Z = 126.0 〜 144.0 mm`（60 層）** も完全連続ループに合流させ、箱型フレームとしてのねじれ剛性を維持する。
2. **開口形状（垂直太柱 ＋ 屋根角 40° 五角形アーチ）**:
   - `Z = 18.0 mm` をフラットな底辺とし、`Z` 方向へ真っ直ぐ垂直（オーバーハング `0°`）に立ち上げた後、上端を**垂直から `40°`（水平から `50°`）の急勾配山形屋根**で閉じ、全頂点に `R4.0 mm` フィレット（頂点はティアドロップ丸め）を付与する。
3. **開口の配置箇所**:
   - **背面縦スパイン（有効長 `204.0 mm`）**: 幅 `48.0 mm` の五角形アーチ大開口を **3 窓** 配置する。窓間の柱幅は `16.0 mm`（上下端マージン各 `14.0 mm`、`14 + 48 + 16 + 48 + 16 + 48 + 14 = 204.0 mm`）とし、造形時はベッドから垂直 `90°` に立ち上がる太柱となるため揺れや反り上がりが発生しない。
   - **底面トレイ床面（内寸奥行 `76.5 mm`）**: 中央に幅 `44.0 mm` の同形状五角形アーチ開口を **1 窓** 配置する（前後各 `16.25 mm` のスタンド受けレールを残しつつ、底面通気を確保）。
   - **天板裏アーム（有効スパン `83.5 mm`）**: 中央に幅 `46.0 mm` の同形状五角形アーチ開口を **1 窓** 配置する。
   - **天板上面ツメ（`45.0 mm`）**: 荷重集中部かつ外観面のため、開口無しのソリッド形状とする。

### 4.4 応力集中対策とエッジ処理

- C 字フック内角・トレイ内角などの応力集中部には `R1.5 〜 R3.0 mm` のフィレットを付与し、割れを防止する。
- ルーター挿入側（右・左開口エッジ）および天板差し込み口には面取りまたはフィレットを施し、機器や家具への傷付きを防ぐ。

## 5. パーツ構成と事前嵌合テストピース

本番造形（数時間）の前に天板厚み（`15.5 mm`）と背面張り出し量（約 `90.0 mm`）へのフィットを短時間・少量の樹脂で確認できるよう、同一スクリプトから以下の 2 ファイルを出力する。

1. **本番モデル (`speaker_stand_router_holder.step`)**:
   - 全幅 `144.00 mm`（`236.6 × 95.0 × 144.0 mm`）、大開口肉抜き入りの完成品モデル。
2. **嵌合テストモデル (`speaker_stand_router_holder_fit_test.step`)**:
   - 天板 C 字フック部〜天板裏アーム〜支柱当てパッド部のみを切り出した、厚さ `12.00 mm`（`0.30 mm × 40 層`）の薄切りテストピース（約 10〜15 分・数 g で造形可能）。
   - 実機に差し込んでガタつきや支柱までの距離を確認し、必要に応じてスクリプト冒頭の定数（`TOP_PLATE_SLOT_GAP` / `OVERHANG_ARM_DEPTH`）を微調整できる設計とする。

## 6. パラメトリック設計と検証項目

- すべての主要寸法・クリアランス・肉厚・窓角度をスクリプト冒頭の大文字定数として定義し、実測微調整に即応できる構成とする。
- 生成後の STEP / ソリッドに対して以下の自動幾何検証を行う。
  1. 単一閉ソリッド（Watertight / Valid Solid、体積 > 0）であること。
  2. バウンディングボックスが `Z_min = 0.0 mm` に接地し、P2S 造形領域（`256 × 256 × 256 mm`）内に余裕をもって収まること。
  3. 天板溝幅（`15.8 mm`）、スタンド受け内寸（`76.5 mm`）、ルーター有効高さ（`204.0 mm`）が設計値通りであること。
